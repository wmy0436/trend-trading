# 股票技术分析技能合集

> WorkBuddy 五大理论体系 + 综合分析系统，为 A 股趋势交易提供从宏观大势到微观 K 线信号的完整技术分析框架。

## 五维分析流水线

```
┌──────────────────────────────────────────────────────────────┐
│                    integrated-stock-analysis                 │
│                    （综合分析 — 总指挥）                       │
├──────────┬──────────┬──────────┬──────────┬─────────────────┤
│ 道氏理论  │  缠论    │  江恩    │  蜡烛图  │   趋势交易      │
│ (方向)    │ (结构)   │ (时空)   │ (信号)   │   (量化执行)    │
├──────────┴──────────┴──────────┴──────────┴─────────────────┤
│  宏观定方向 → 结构定框架 → 时空定位置 → 信号定确认 → 执行定规则 │
└──────────────────────────────────────────────────────────────┘
```

### 各体系定位

- **道氏理论** → 定 **方向**：大势是牛还是熊？趋势是主要还是次级？
- **缠论** → 定 **结构**：当前处于哪一段笔/线段？中枢在哪？走势类型如何？
- **江恩选股** → 定 **时空**：时间窗口到位了吗？支撑阻力位在哪？3 点法则确认突破？
- **蜡烛图** → 定 **信号**：K 线形态是反转还是持续？信号有效性需要什么条件增强？
- **趋势交易** → 定 **执行**：入场条件量化触发了吗？仓位多少？止损止盈怎么设？

五维共振时操作置信度最高，信号矛盾时由综合分析系统给出优先级裁决。

## 使用方式

这些技能是为 [WorkBuddy](https://www.codebuddy.cn/) 平台设计的，可直接导入使用：

1. 将对应技能文件夹复制到 `~/.workbuddy/skills/` 目录下
2. 在 WorkBuddy 对话中提及相关关键词即可触发
   - "用缠论分析 XXX" → 触发 chan-theory
   - "全面分析 XXX" → 触发 integrated-stock-analysis
   - "道氏理论判断趋势" → 触发 dow-theory
   - 等等

### 推荐分析流程

对一只标的进行完整技术分析时，建议按以下顺序调用：

1. **道氏理论** → 先定大势方向
2. **缠论** → 画结构、找中枢和买卖点
3. **江恩选股** → 时间周期与关键价位定位
4. **蜡烛图** → 确认 K 线形态信号
5. **趋势交易** → 量化入场/出场条件
6. **综合分析** → 五维交叉验证，给出统一评分与操作建议

也可直接使用 **integrated-stock-analysis** 一步到位，它会自动串联以上流程。

## 设计原则

- **全部规则量化可执行** — 每个判断都有明确的数值条件，不做模糊描述
- **多技术共同参照** — 单一信号不构成操作依据，必须得到至少两个维度验证
- **优先级裁决** — 信号矛盾时不是简单投票，而是按"方向 > 结构 > 时空 > 信号 > 执行"裁决
- **A股适配** — 所有规则基于 A 股市场特征设计（T+1、涨跌停板、散户主导等）
