## 系统概述

本系统是一套**面向中国 A 股市场**的系统性趋势交易方法论，从三个维度构建交易决策框架：

| 维度 | 内容 | 定位 |
|------|------|------|
| **技术分析** | 均线系统 + 波浪理论 + 技术指标 + 量价关系 | 判断方向与时机 |
| **周期与资金** | 市场周期 + 四类资金博弈 + 政策-经济-资金-行情链条 | 判断环境与对手 |
| **心理与纪律** | 十大心理陷阱 + 取舍框架 + 情绪冷却机制 | 管理自我 |

**一句话概括**：均线系统定方向，波浪理论定阶段，技术指标定信号，资金分析定环境，交易心理定执行。

## 核心设计理念

### 1. 方向永远大于技巧

趋势不对，努力白费。不与趋势为敌是股市生存的底线。

### 2. 全部规则量化可执行

拒绝模糊表述。每个入场条件、止损阈值、止盈规则都有明确的量化标准，消除"感觉"和"也许"。

### 3. 三重验证共振

单一信号不操作。均线方向 + 波浪位置 + 技术指标三重验证共振时，置信度最高。

### 4. 先防守后进攻

止损是交易系统的基石。先想好"错了怎么办"，再想"对了怎么办"。

### 5. 八成时间等待

真正"方向 + 空间 + 胜率"同时具备的时间只占约 20%，80% 时间应该空仓或轻仓等待。

## 模块详解

### 一、趋势判断框架

| 模块 | 核心规则 |
|------|---------|
| 1.1 核心原则 | 方向永远大于技巧，顺势而为 |
| 1.2 三要素 | 方向（均线）+ 强度（量价/指标）+ 周期（日线+周线共振） |
| 1.3 三种状态 | 趋势行情(20%) / 震荡行情(60%) / 极端行情(20%) |
| 1.4 极端行情量化 | 3日涨≥25%且换手≥15%=极端上涨；3日跌≥15%且量>2倍=极端下跌 |
| 1.5 多头有效性验证 | 250日线斜率>0 + 偏离度≤30% + 无顶背离 = 有效多头 |

### 二、入场条件

| 模块 | 核心规则 |
|------|---------|
| 2.1 标准选股 | 日线所有均线在250日线上 + 多头排列 + 周线在60周线上 |
| 2.2 买入操作 | 5日线回踩±2%入场 + 量能确认 |
| 2.3 买坑标准 | 回踩20日线不破 + 缩量≤70% + KDJ超卖金叉 |
| 2.4 禁止操作 | 均线空头排列/假多头/大盘弱势 不操作 |

### 三、持仓管理

| 模块 | 核心规则 |
|------|---------|
| 3.1 减仓条件 | 5日线拐头/放量滞涨/偏离250日线>30% |
| 3.2 加仓条件 | 放量突破前高+MACD红柱放大+20日线支撑 |
| 3.3 仓位控制 | 单标的≤30% + 总仓位按趋势状态分级(强趋势80%/震荡40%/弱势20%) |

### 四、止盈与止损

| 模块 | 核心规则 |
|------|---------|
| 4.1 止损 | 硬止损-7% + 5日线止损 + 20日线止损（三道防线） |
| 4.2 止盈 | 目标位止盈(斐波那契1.618/2.618) + 移动止盈(5日线跟踪) |
| 4.3 交易口诀 | 10条量化版口诀 |
| 4.4 交易日志 | 标准化日志模板（含技术指标/资金/心理三维度） |

### 五、波浪理论定位

8 浪完整周期与均线系统、MACD、EXPMA 的交叉验证关系，用于判断趋势当前处于哪个阶段。

### 六~七、底部与反弹

- 底部三信号：缩量止跌 + KDJ超卖金叉 + MACD底背离
- 反弹三判断：量价配合 + 均线支撑 + 指标共振

### 八、大盘与基本面

- 大盘否决权：大盘弱势时，个股不操作
- 基本面门槛：PE/PB/ROE/营收增速 四维度过滤

### 九、复盘流程

每日标准复盘框架，涵盖持仓检查 + 关注标的 + 市场环境 + 心理自检。

### 十~十一、原则与心理

- 7 条核心原则 + 5 条纪律红线
- 心理防线的认知层与执行层

### 十三、技术指标量化分析【v3.0+】

| 指标 | 核心功能 | 关键规则 |
|------|---------|---------|
| **MACD** | 趋势跟踪 + 背离识别 | 零轴上方金叉=强信号；两次底背离=反转确认 |
| **KDJ** | 超买超卖 + 拐点判断 | 趋势中KDJ可长期钝化，不作为独立依据 |
| **RSI** | 强弱判断 + 背离辅助 | RSI>80超买，<20超卖；与MACD背离交叉验证 |
| **BOLL** | 波动率 + 支撑压力 | 收口=变盘在即；缩量沿下轨运行=弱势 |
| **EXPMA** | 入场时机精修【v3.1】 | SMA是战略，EXPMA是战术；EXPMA先预警，SMA后确认 |

### 十四、市场周期与资金分析【v3.0+】

| 内容 | 核心框架 |
|------|---------|
| 四类资金 | 机构/游资/量化/散户——各自特征与行为模式 |
| 四周期链 | 政策 → 经济 → 资金 → 行情 的传导逻辑 |
| 长期资本 | 建仓节奏识别与跟随策略 |

### 十五、交易心理深化【v3.0+】

10 大心理陷阱（确认偏误/锚定效应/损失厌恶/过度自信等）+ 自我否定原则 + 情绪冷却机制。

### 十六、市场环境适配【v3.0+】

| 环境 | 特征 | 操作策略 |
|------|------|---------|
| 放量趋势 | 量价齐升 | 标准入场 + 仓位可至 80% |
| 缩量震荡 | 成交萎缩 | 减半仓位 + 严格止损 |
| 存量博弈 | 资金不增不减 | 只做龙头 + 快进快出 |
| 恐慌下跌 | 非理性抛售 | 空仓等待 + 不抄底 |
| 慢牛 | 温和上行 | 持股为主 + 不频繁换手 |

### 十七、取舍框架【v3.0+】

四大取舍原则：取趋势舍震荡 / 取龙头舍跟风 / 取确定舍幻想 / 取纪律舍侥幸。

## 快速上手

### 最小可用路径（5 分钟）

1. **看均线**：5日 > 20日 > 60日 > 250日 且 250日线斜率 > 0？→ 有效多头
2. **看大盘**：大盘不在弱势？→ 大盘否决权通过
3. **看量价**：成交量 ≥ 5日均量？→ 量能确认
4. **看指标**：MACD零轴上方 + KDJ金叉 + RSI > 50？→ 指标共振
5. **入场**：5日线回踩 ±2% 买入，止损设 -7%

### 完整分析路径（系统性分析）

1. 趋势判断（1.1~1.5）→ 确认方向
2. 波浪定位（5.1~5.7）→ 确认阶段
3. 入场条件（2.1~2.4）→ 确认时机
4. 技术指标评分（13.6）→ 量化评分
5. 市场环境适配（16.1）→ 确认策略
6. 资金分析（14.1）→ 确认对手
7. 心理自检（15.1）→ 确认状态
8. 执行 + 记录交易日志（4.4）
