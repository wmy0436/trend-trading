# 股票综合分析系统 (Integrated Stock Analysis System)

> **设计理念**：五大理论体系各自独当一面，但单打独斗都有盲区。本系统将五者串联为
> 一条完整分析流水线——宏观定方向、结构定框架、时空定位置、信号定确认、量化定执行。
> 五维共振时，操作置信度最高；信号矛盾时，系统给出优先级裁决规则。

## 二、统一分析流水线——六步法

### 步骤一：大势定调（道氏理论主导）

**目标**：确定当前市场处于牛/熊/震荡市的哪个阶段，这是所有后续分析的前提。

**检查项**：

1. **三重运动定位**：
   - 基本运动方向是什么？（看周线/月线的趋势线方向）
   - 当前次级运动处于什么位置？（回调还是反弹？幅度达到1/3~2/3了吗？）
   - 日常波动的噪音是什么？（哪些短期波动可以忽略）

2. **市场阶段判断**：
   - 牛市：积累 → 公众参与 → 过度投机？
   - 熊市：派发 → 恐慌 → 绝望？
   - 震荡：在什么区间内横盘？

3. **指数互证**（A股版）：
   - 上证 ⇔ 深证：是否同创新高/新低？
   - 沪深300 ⇔ 中证500：大盘/中小盘是否一致？
   - 个股所在板块指数是否与大盘同向？

4. **123法则与2B法则检查**：
   - 是否有趋势反转信号？
   - 趋势线是否被突破？

**输出**：大势评分 + 允许操作方向（只做多/只做空/可双向/不操作）

---

### 步骤二：结构拆解（缠论主导）

**目标**：用缠论框架厘清个股的走势结构，定位中枢和买卖点。

**检查项**：

1. **走势类型判断**：
   - 当前是盘整走势（1个中枢）还是趋势走势（≥2个同向中枢）？
   - 走势命名：走到 a-A-b-B-c 的哪个位置？

2. **中枢定位**：
   - 最近的ZG（中枢高点）和ZD（中枢低点）在哪？
   - 中枢是否已完成？（第三类买卖点是否出现）
   - 是否有奔走中枢？

3. **买卖点识别**：
   - 一买/一卖：走势完结转折点（背驰引发）
   - 二买/二卖：回调/反弹不破前低/前高
   - 三买/三卖：出中枢后回踩/反弹不进入中枢 ⭐最重要

4. **背驰判断**：
   - 用区间套多级别确认（日线→30分钟→5分钟）
   - 比较a/A/b/B/c的MACD面积或绝对长度
   - 是否出现双重/多重背驰？

5. **级别确认**：
   - 当前分析级别是什么？（日线/30分钟）
   - 大级别走势支持当前判断吗？

**输出**：走势类型 + 中枢区间[ZD, ZG] + 当前是否有买卖点 + 买卖点类型

---

### 步骤三：时空精修（江恩主导）

**目标**：用江恩的时间周期和空间规则精修入场时机和止损价位。

**检查项**：

1. **时间周期检查**：
   - 从最近重要顶/底起算，是否运行到关键时间节点（7/10/14/20/21天，30/60/90/120/180天）？
   - 当前日期是否接近关键季节日期（3/21、6/22、9/23、12/22等）？
   - 回调/反弹时间是否符合江恩周期（牛市回调≤2~3月，熊市反弹≤6~7周）？

2. **支撑阻力定位**：
   - 50%回撤位在哪？当前价格与50%位的关系？
   - 1/4、1/2、3/4、5/8、7/8关键分割位在哪？
   - 历史恐慌年份支撑位是否在附近？
   - 第几次触及关键支撑/阻力？

3. **3点法则应用**：
   - 有效突破确认：超过关键价位3点了吗？
   - 止损设定：买入价下方1~3点
   - 回调买入：突破后回调1~3点

4. **成交量验证**（江恩版）：
   - 顶部是否出现巨量派发信号？
   - 底部是否出现缩量衰竭信号？
   - 突破时是否有成交量配合？

5. **活跃度筛选**：
   - 年震荡幅度≥20点？日均活跃度如何？
   - 当前处于行情四阶段的哪个阶段？

**输出**：时间窗口预警 + 关键支撑/阻力位 + 精确止损位建议

---

### 步骤四：信号确认（蜡烛图主导）

**目标**：在缠论买卖点位置和江恩关键价位处，用蜡烛图形态做最终信号确认。

**检查项**：

1. **反转形态识别**：
   - 当前位置是否有反转K线形态？
   - 形态强度如何？（弃婴>十字黄昏星>吞没>锤子线）
   - 形态是否满足严格定义？（如乌云盖顶需穿入50%以上）

2. **持续形态识别**：
   - 趋势中是否有窗口（跳空缺口）？
   - 窗口是否被回填？

3. **十字线专题**：
   - 上升趋势中出现十字线 → 顶部反转警告
   - 下降趋势中十字线 → 通常不构成反转
   - 是什么类型的十字线？（墓碑/蜻蜓/长腿/三星）

4. **多技术共同参照**：
   - 蜡烛图信号是否与趋势线/均线/摆动指数共振？
   - 同一位上是否汇聚了多个技术信号？
   - 成交量是否验证蜡烛图信号？

**输出**：K线信号类型 + 信号强度（1-5星）+ 是否需要其他工具验证

---

### 步骤五：量化执行（趋势交易主导）

**目标**：在以上四维分析的基础上，用量化规则确定是否操作、仓位多少、止损止盈在哪。

**检查项**：

1. **大盘否决权**（优先级最高）：
   - 三大指数是否跌破20日线？
   - 涨跌家数比是否<1:2？
   - 主力资金是否连续3日净流出>500亿？
   - **以上任一触发 → 所有新开仓暂停**

2. **选股条件核查**：
   - 日线均线是否在250日线之上？
   - 均线是否多头排列（5>20>60>250）？
   - 均线有效性验证（有效多头/高位多头/假多头）？
   - 周线是否在60周线之上？

3. **基本面门槛**：
   - PE>0且<行业均值×1.5？
   - ROE>8%？
   - 净利率>5%？
   - 营收增速>0？

4. **市场环境适配**：
   - 当前是什么市？（放量趋势/缩量震荡/存量博弈/恐慌下跌/慢牛上行）
   - 对应仓位上限是多少？
   - 采用哪种入场策略？

5. **仓位与止损**：
   - 总仓位按市场状态规则确定
   - 单票≤总仓位8%
   - 双轨止损：-7%或跌破20日线，取更近者
   - 江恩3点止损与趋势-7%止损：取江恩止损（更紧）作为第一止损线，趋势止损作为最后防线

**输出**：操作决策（买入/持有/减仓/离场/观望）+ 仓位 + 止损价 + 止盈目标

## 三、统一评分卡（五维共振评分）

### 3.1 评分体系（总分100分）

| 维度 | 评分项 | 满分 | 得分规则 |
|------|-------|------|---------|
| **道氏-方向** | 主要趋势方向明确 | 10 | 牛/熊趋势明确+10，震荡市+5，方向不明+0 |
| **道氏-阶段** | 处于安全可操作阶段 | 8 | 牛市积累/公众参与+8，过度投机+3，熊市绝望末期+5 |
| **道氏-互证** | 指数互证一致 | 6 | 两大指数同向+6，背离+0 |
| **缠论-走势** | 走势类型有利 | 12 | 趋势走势（2浪/3浪初）+12，盘整走势+6，趋势末端+3 |
| **缠论-买卖点** | 有明确买卖点 | 12 | 三买+12，二买+8，一买+4（新手0），无买点+0 |
| **缠论-背驰** | 背驰有利于操作方向 | 8 | 底背驰（做多）+8，顶背驰（做空）+8，无背驰+4 |
| **江恩-时间** | 处于有利时间窗口 | 6 | 关键时间节点+周期共振+6，单一周期+3，无信号+0 |
| **江恩-空间** | 价格在关键支撑/阻力位 | 8 | 50%回撤位+恐慌支撑附近+8，其他关键位+4 |
| **江恩-成交量** | 量价配合符合趋势方向 | 6 | 方向一致+6，背离+0 |
| **蜡烛图-信号** | 有确认反转/持续信号 | 8 | 4-5星形态+8，2-3星+4，无信号+0 |
| **蜡烛图-共振** | 多技术共同参照 | 4 | 3个以上工具共振+4，1-2个+2，无+0 |
| **趋势-条件** | 符合标准选股条件 | 8 | 全部符合+8，部分符合+4，不符合+0 |
| **趋势-环境** | 市场环境适合操作 | 4 | 趋势市+4，震荡市+2，恐慌市+0 |

### 3.2 评分解读

| 总分 | 评级 | 五维共振度 | 操作建议 |
|------|------|-----------|---------|
| ≥85 | ⭐⭐⭐⭐⭐ 强烈推荐 | 五维高度共振 | 正常仓位入场/满仓持有 |
| 70~84 | ⭐⭐⭐⭐ 推荐 | 四维共振 | 轻仓入场/持有 |
| 55~69 | ⭐⭐⭐ 谨慎 | 三维共振 | 试错仓（3%以下）或观望 |

### 3.3 否决项（硬否决—一票否决，不论评分多少）

| 否决条件 | 来源理论 | 说明 |
|---------|---------|------|
| 大盘否决权触发（趋势交易8.1） | 道氏+趋势 | 大盘破位，个股再好也不操作 |
| 均线假多头（趋势交易1.5） | 趋势 | 250日线斜率≤0，多头不可靠 |
| 年震荡幅度<10点（江恩否决项） | 江恩 | 不活跃不操作 |
| 场外证券/新股（江恩否决项） | 江恩 | 90%会消失 |
| 未设止损 | 江恩+趋势 | 每笔必设 |

### 3.4 重要提示（不否决，但需特别关注）

以下条件触发时不取消操作资格，但在报告中以 ⚠️ 明确标注，
建议降低仓位或等待确认：

| 提示条件 | 说明 | 建议应对 |
|---------|------|---------|
| **PE亏损（PE<0）** | 公司处于亏损状态，趋势可能不稳固 | 仓位降至正常50%，止损收紧至-5% |
| **PE过高（PE>行业均值×2）** | 估值偏高，回调风险大 | 等回调至20日线再入场 |
| **偏离250日线>30%** | 高位运行，追高风险大 | 等回调至20日线，不追高 |
| **ROE<8%** | 盈利能力偏弱 | 优先选择ROE达标的同板块标的 |
| **净利率<5%** | 盈利质量不佳 | 配合营收增速综合判断 |
| **营收增速≤0** | 业务萎缩信号 | 除非行业周期底部反转，否则回避 |
| **换手率>15%** | 筹码松动，游资主导 | 仅做短线，不做趋势持仓 |

## 四、五理论冲突裁决规则

### 4.1 方向冲突裁决

当不同理论对趋势方向的判断不一致时：

| 冲突类型 | 裁决规则 | 理由 |
|---------|---------|------|
| 道氏vs缠论方向矛盾 | **以道氏为主** | 道氏看大级别趋势，缠论可能只看到小级别波动 |
| 道氏vs趋势交易方向矛盾 | **以道氏为主** | 道氏是趋势交易的理论基础，方向矛盾时回看大级别 |
| 缠论vs江恩方向矛盾 | **以缠论为主** | 缠论结构分析比江恩时间预判更直接 |
| 蜡烛图vs其他方向矛盾 | **以其他主** | 蜡烛图是微观信号，可能只是短期波动而非趋势改变 |

### 4.2 买卖点冲突裁决

| 冲突类型 | 裁决规则 | 理由 |
|---------|---------|------|
| 缠论三买出现但江恩时间未到 | **以缠论为准** | 三买确认即操作，时间只是辅助 |
| 蜡烛图反转但缠论无买卖点 | **不操作** | 无缠论买卖点支撑的K线信号可信度低 |
| 江恩支撑位 + 蜡烛图反转 | **高置信度买入** | 两者共振=多技术共同参照 |
| 趋势交易买入信号但缠论在顶部 | **不买入** | 缠论结构位置优先于均线信号 |

### 4.3 止损设置优先级

| 止损来源 | 幅度 | 优先级 | 使用场景 |
|---------|------|--------|---------|
| 江恩3点止损 | 约-3%~-5% | 第一止损线 | 精确入场后的紧止损 |
| 趋势交易-7%止损 | -7% | 第二止损线 | 宽止损保护 |
| 趋势交易20日线止损 | 取决于股价 | 第三止损线 | 趋势破坏确认 |

> **执行规则**：入场时设江恩3点止损为第一止损线（最紧），趋势-7%止损为硬止损底线。
> 如果股价运行有利，逐步将止损上移至保利润止损（江恩4.1）。

## 八、使用方式

当用户提出以下问题时，调用本Skill进行综合分析：

1. **"全面分析这只股票"** → 执行完整六步法 + 输出分析报告
2. **"XX股票评分多少？"** → 执行统一评分卡
3. **"用所有理论帮我看看XX"** → 五维交叉分析
4. **"XX和XX两个信号矛盾怎么办？"** → 参照第四章冲突裁决
5. **"快速判断能不能买XX"** → 执行5.1快速判断流程
6. **"帮我写XX股票的完整分析报告"** → 使用第六章报告模板
7. **"现在市场处于什么阶段？"** → 道氏理论全程分析 + 其他理论补充验证
8. **"帮我做个多理论交叉验证"** → 逐维度分析 + 冲突裁决

### 与其他Skill的协同

- **本Skill是"总指挥"**：判断大方向、协调各理论、做出最终决策
- **各独立Skill是"专家"**：当需要某个理论的深入分析时，调用对应的独立Skill获取详细规则
- **趋势交易Skill是"执行者"**：最终的仓位、止损、止盈以趋势交易Skill的量化规则为准（在方向由本Skill确认的前提下）
