# 五维分析速查卡

## 快速决策流程

```
1. 大盘否决权触发？ → 停止分析，不开仓
2. 道氏趋势方向？   → 下跌趋势 → 只减仓不做多
3. 缠论走势位置？   → A浪/B浪/C浪 → 不操作
4. 江恩时间/空间？   → 不到关键位 → 等待
5. 蜡烛图信号？     → 无反转信号 → 等待
6. 趋势交易条件？   → 不满足 → 不操作
7. 统一评分？       → <55分 → 不操作
   ↓ 全部通过
8. 决定：买入/持有，仓位X%，止损Y元
```

## 五维共振速查

| 共振维数 | 操作 | 仓位上限 |
|---------|------|---------|
| 5维共振 | 全力做多/做空 | 正常仓位 |
| 4维共振 | 正常操作 | 正常仓位×70% |
| 3维共振 | 试错仓 | 3% |
| 2维共振 | 观望 | 0% |
| 1维或无 | 反向操作/空仓 | 0% |

## 理论优先级速查

| 决策类型 | 主理论 | 次理论 |
|---------|--------|--------|
| 趋势方向 | 道氏 | 趋势(均线) |
| 走势阶段 | 缠论 | 道氏 |
| 入场时机 | 缠论+江恩 | 蜡烛图 |
| 止损价位 | 江恩(紧)+趋势(宽) | — |
| 仓位管理 | 趋势 | 江恩 |
| K线确认 | 蜡烛图 | — |
| 离场信号 | 趋势(死叉)+江恩(派发) | 蜡烛图(反转) |

## 否决项一票否决清单

- [ ] 大盘否决权触发（三大指数破20日线/涨跌比<1:2/资金连续流出）
- [ ] 年震荡幅度<10点
- [ ] 场外证券/新股
- [ ] 均线假多头（250日线斜率≤0）
- [ ] PE<0（亏损）
- [ ] 未设止损
