# 江恩选股系统 v1.0 (Gann Stock Selection System)

> **理论来源**：威廉·D·江恩（William D. Gann）三本原著
> - 《江恩股市定律》(Truth of the Stock Tape, 1923)
> - 《新股票趋势探测器》(New Stock Trend Detector, 1936)
> - 《江恩核心股票教程》(Gann Core Stock Tutorial)
>
> **设计理念**：江恩交易体系以"3点法则"为最核心的数字规则，贯穿止损、突破确认、支撑验证等所有环节。配合时间周期、成交量、支撑阻力三大维度进行交叉验证，构成完整的选股-入场-持仓-出场闭环。

---

## 一、3点法则 —— 江恩体系的最核心规则

> 3点法则是江恩所有交易规则中重复次数最多、贯穿始终的数字参数。几乎所有入场、止损、突破确认都围绕3点展开。

### 1.1 3点法则全规则表

| 应用场景 | 3点规则 | 说明 |
|---------|---------|------|
| **止损** | 买入点下方 **1~3点**（默认3点最安全） | 首次交易最大风险不超过5点 |
| **突破确认** | 股价超过原来高点 **3点** | 突破3点才算有效突破 |
| **跌破确认** | 股价跌破原来低点 **3点** | 跌破3点确认趋势反转 |
| **买入回调** | 突破后回调 **1~3点** 时买入 | 回调不破原高点下方3点 |
| **支撑反弹** | 跌破历史低点后反弹超过原低点 **3点** | 确认最后一波抛盘结束 |
| **双重/三重底** | 同一价位附近维持 **2~3周** | 活跃市场可缩短至2~3天 |

### 1.2 价格区间与止损幅度适配

| 股价区间 | 止损幅度 | 适用场景 |
|---------|---------|---------|
| 10~30 美元 | 2个点（底部或收盘价下方） | 低价股 |
| 30~90 美元 | 2~3个点 | 中价股 |
| 90~150 美元 | 3个点 | 高价股 |
| 150+ 美元 | 3~5个点，极高时可10点 | 极高价股 |

> **执行铁律**：每笔交易必须预设止损单，触达即执行，不犹豫、不拖移。

## 二、选股框架 —— 六大维度交叉筛选

### 2.1 维度一：活跃度筛选（第一道过滤）

江恩反复强调：**只做最活跃的领头股，不做窄幅震荡的冷门股。**

| 筛选条件 | 量化标准 | 操作 |
|---------|---------|------|
| **年震荡幅度** | ≥ 20点（理想20~100点） | 可操作 |
| **年震荡幅度** | 5~10点 | 放弃，利润空间不足 |
| **每日活跃度** | 纽约证交所/主流交易所最活跃榜单 | 首选 |
| **场外证券/新股** | — | 一律不碰（90%会消失） |
| **窄幅震荡股** | 长期在狭小区间波动，成交量稀少 | 不碰，除非放量突破区间 |

> **赚大钱靠的是股价震荡幅度，不是股息。**

### 2.2 维度二：相对强弱筛选（核心选股方法）

江恩选股最核心的方法：**同时比较同板块股票与板块平均指数，找出相对最强/最弱的个股。**

#### 强势股识别（做多候选）

| 编号 | 强势信号 | 量化标准 |
|------|---------|---------|
| S1 | **底部逐年抬高** | 每年底部比上一年更高，形成"累进式底部" |
| S2 | **突破前一年高点** | 股价超过上一年最高价3个点 |
| S3 | **萧条期抗跌** | 熊市中保持高于前期支撑位（如高于1920年底部27点） |
| S4 | **提前大盘见底** | 比大盘早筑底（如提前8个月） |
| S5 | **率先突破历史顶部** | 在同板块中率先突破多年高点 |
| S6 | **逆市创新高** | 在大盘/同板块下跌时创新高 |
| S7 | **窄幅吸筹后放量突破** | 在狭窄区间维持数周/数月+成交量萎缩→放量突破区间上限 |

#### 弱势股识别（做空候选/回避）

| 编号 | 弱势信号 | 量化标准 |
|------|---------|---------|
| W1 | **同板块创新高时未达前高** | 板块其他股创新高，该股未能突破自身前高 |
| W2 | **跌破多年支撑** | 跌破维持数年/十数年的支撑价位 |
| W3 | **未突破前一年高价位** | 其他强势股突破时，该股未突破 |
| W4 | **接近前高但未突破** | 长时间（数周/数月）接近前高但始终未突破3点 |
| W5 | **反弹仅2~3个月后转跌** | 熊市反弹不超过6~7周，第三个月不创新高 |
| W6 | **提前大盘见顶** | 比大盘早见顶（如提前11个月） |

### 2.3 维度三：支撑与阻力（入场/出场定位）

#### 历史支撑/阻力层级

| 层级 | 判定方法 | 重要性 |
|------|---------|--------|
| **年度高/低点** | 前一年/前几年最高价和最低价 | ⭐⭐⭐ |
| **恐慌年份支撑** | 在极端恐慌年份获得支撑的价位（如1907/1914/1921/1929/1932年底部） | ⭐⭐⭐⭐⭐ |
| **15~20年历史价位** | 长期历史高低点，时间越久越重要 | ⭐⭐⭐⭐⭐ |
| **50%回撤位** | 极限高点和低点之间的中点 | ⭐⭐⭐⭐⭐ |
| **1/4、3/4、5/8、7/8位** | 100为基准的关键分割位 | ⭐⭐⭐⭐ |

#### 50%规则（江恩称为"仅遵循此规则就能发财"）

| 场景 | 规则 | 操作 |
|------|------|------|
| **高点50%回落** | 股价从最高点下跌至50%位置 | **买入**，止损设前期底部下方3点 |
| **低点50%反弹** | 股价从远低于50%位置首次触及50% | **卖出/做空**，止损不超过50%上方3点 |
| **极限高低点50%** | 极限低点和极限高点之间的中点 | 重要买卖位 |
| **突破50%向上** | 低位盘整很长时间后突破50% | **强势信号**，预示后市更高 |
| **跌破50%向下** | 股价跌破最高价的50% | **弱势信号**，预示后市更低 |

#### 第4次触及规则

| 场景 | 规则 | 止损 |
|------|------|------|
| 第4次触及同一顶部 | 几乎一定会突破向上 | 顶部上方1点止损 |
| 第4次触及同一底部 | 几乎一定会跌破向下 | 底部下方1点止损 |
| 第1/2/3次回调到老顶部 | 买入安全 | 止损下方3点 |
| 第4次回调到同一价位 | **买入危险**，通常会跌破 | — |

### 2.4 维度四：成交量（趋势确认）

> 江恩成交量规则是判断顶底和趋势转折的核心验证工具。

| 市场阶段 | 成交量特征 | 信号含义 |
|---------|-----------|---------|
| **顶部区域** | 大幅放量（单周接近流通股一半） | 派发信号，即将转跌 |
| **顶部次级反弹** | 成交量比前一次顶部明显减少 | 确认顶部成立 |
| **快速下跌后** | 巨量成交 | 可能形成尖底+快速反弹 |
| **长期下跌末端** | 成交量极度萎缩（如周成交降至千股级别） | 抛盘衰竭，即将反转向上 |
| **底部蓄势期** | 长时间窄幅波动+成交量稀少 | 吸筹/积蓄上涨能量 |
| **二次下跌** | 成交量比底部时更少 | 健康回踩，确认支撑 |
| **突破时** | 放量突破区间 | 有效突破确认 |
| **放量滞涨** | 大成交量但涨幅极小 | 顶部派发信号 |

### 2.5 维度五：时间周期

江恩的时间规则用于判断趋势转折的时机，与价格信号配合使用。

#### 核心时间周期

| 周期类型 | 时间参数 | 应用 |
|---------|---------|------|
| **超短线** | 2天（急跌后第3天反弹） | 活跃市场急跌抄底 |
| **短线底部确认** | 2~3天（活跃市）/ 2~3周（普通市） | 等待底部形成 |
| **牛市回调** | 不超过2~3个月，第3个月恢复向上 | 趋势延续确认 |
| **熊市反弹** | 不超过6~7周（约2个月） | 弱势确认 |
| **极度弱势反弹** | 不超过1个月 | 极弱势确认 |
| **快速行情** | 6~7周后出现次级反转 | 中期趋势转变 |
| **关键日** | 第7、10、14、20、21天 | 短期趋势变化 |
| **月度关键日** | 6~7日、9~10日、14~15日、19~20日、23~24日、29~31日 | 月度趋势转折 |
| **关键月** | 第30、60、90、120、180天 | 自重要顶底起算 |

#### 江恩年度周期（大级别）

| 周期 | 规则 | 说明 |
|------|------|------|
| **5年周期** | 牛市：2年涨+1年跌+2年涨=5年 | 第59~60个月留意趋势变化 |
| **5年熊市** | 熊市：2年跌+1年涨+2年跌=5年 | — |
| **7年周期** | 3年+4年 | 自任意绝对底部起算 |
| **10年周期** | 任意顶部+10年≈下一顶部；任意底部+10年≈下一底部 | 历史重演 |
| **20年周期** | 最重要周期之一 | — |
| **30年周期** | 含3个10年周期 | — |
| **50年周期** | 最大周期，极限高低点出现 | — |

#### 关键季节日期

| 日期 | 角度 | 含义 |
|------|------|------|
| 1月5~6日 | ~15° | 年初重要高低点 |
| 1月20~21日 | 30° | 次级趋势变化 |
| 3月21日 | 90° | 春分，重要趋势变化 |
| 5月6日 | 135° | 重要趋势变化 |
| 6月22日 | 180° | 夏至，季节性变化 |
| 8月8日 | 225° | 极其重要趋势变化 |
| 9月23日 | 270° | 秋分，趋势变化 |
| 11月8日 | 315° | 重要顶底 |
| 12月22日 | 360° | 冬至，重要趋势变化 |

### 2.6 维度六：板块轮动

| 规则 | 量化标准 |
|------|---------|
| **板块选择** | 从每个活跃板块选1只，总共4~5只，均摊风险 |
| **板块比较** | 只做年震荡20~100点的板块，放弃5~10点板块 |
| **领涨股更替** | 同一板块不会永远领涨，5~10年后被新板块取代 |
| **新兴行业** | 关注发展迅速的新兴工业（江恩1923年预判飞机/广播/化工） |
| **弱势板块** | 全市场创新高时某板块仅小幅反弹=正在被大量派发 |

## 三、入场时机 —— 六种买入模式

### 3.1 模式一：双底/三重底买入

| 条件 | 操作 | 止损 |
|------|------|------|
| 股价在同一低位附近维持 **2~3周**（活跃市2~3天） | 在底部附近买入 | 最低周均价下方 **3点** |
| 股价第二次/第三次触及同一底部 | 买入 | 底部下方1~3点 |
| 相隔 **数周或数月** 的双重/三重底 | 买入（最可靠） | 底部下方3点 |

### 3.2 模式二：突破前高买入

| 条件 | 操作 | 止损 |
|------|------|------|
| 股价超过原高点 **3点**（确认有效突破） | 回调1~3点时买入 | 原高点下方3点 |
| 第二次创新高 | **比第一次更安全** | 原高点下方3点 |
| 突破 **上一年最高价** 3点后回调 | 买入 | 原年高点下方3点 |
| 突破 **历史最高价** | 原高点区域即安全买点 | 原高点下方3点 |

### 3.3 模式三：突破吸筹区间买入

| 条件 | 操作 | 止损 |
|------|------|------|
| 股价在狭窄区间维持 **数周/数月** + 成交量萎缩 | 突破区间上限时买入 | 区间下限下方3点 |
| 吸筹区间维持 **数月至数年** | 突破后行情幅度极大 | 突破前低点下方3点 |
| 突破10年最高价位 | 强烈看涨 | 原10年高点下方3点 |

### 3.4 模式四：50%回撤买入

| 条件 | 操作 | 止损 |
|------|------|------|
| 股价从最高点下跌至 **50%** 位置 | 买入 | 前期底部下方3点 |
| 极限高点和低点之间的 **中点** | 买入 | 中点下方1~3点 |

### 3.5 模式五：下跌衰竭买入

| 条件 | 操作 | 止损 |
|------|------|------|
| 长期下跌后成交量极度萎缩+窄幅波动 | 等待放量突破后买入 | 最低点下方3点 |
| 跌破历史低点后反弹超过原低点 **3点** | 买入 | 原低点下方3点 |
| 活跃市场连续暴跌 **2天** | 第3天买入 | 3点止损 |

### 3.6 模式六：领涨股优先买入

| 条件 | 操作 |
|------|------|
| 同板块中率先突破历史顶部 | 优先买入 |
| 底部逐年抬升+萧条期抗跌 | 优先买入 |
| 提前大盘见底+率先恢复上涨 | 优先买入 |

## 四、出场与止损

### 4.1 止损铁律

| 规则 | 量化 | 适用范围 |
|------|------|---------|
| **初始止损** | 买入价下方1~3点（默认3点） | 所有交易 |
| **最大容忍** | 不超过5点 | 首次交易 |
| **保利润止损** | 每周最低点下方1/2/3/5点 | 已有利润后 |
| **极高价位止损** | 每天最高价下方5~10点 | 极高价位股 |

### 4.2 派发信号（卖出/做空）

| 编号 | 派发信号 | 量化标准 |
|------|---------|---------|
| 1 | **顶部巨量** | 日成交量达数百万股或单周接近流通股一半 |
| 2 | **快速反复震荡** | 顶部区间大幅震荡+大成交量 |
| 3 | **增加股息/分红** | 高价位增加股息=派发诱饵 |
| 4 | **双重顶/三重顶** | 多次触及同一高位但未突破3点 |
| 5 | **窄幅震荡后跌破** | 维持数月的派发区间被向下跌破 |
| 6 | **第4次触及顶部** | 第4次触及同一价位 = 即将突破向下或向上 |
| 7 | **放量滞涨** | 大成交量但价格几乎不涨 |
| 8 | **次级反弹成交量递减** | 每次反弹成交量比前一次减少 |

### 4.3 离场信号

| 信号 | 操作 |
|------|------|
| 跌破买入价下方3点 | 无条件止损 |
| 跌破重要支撑位3点 | 全部离场 |
| 顶部派发信号确认（见4.2） | 全部离场/做空 |
| 跌破吸筹区间下限 | 全部离场 |
| 买入后第1天收盘亏损 | 警惕，可能判断错误 |
| 买入后第3天仍亏损 | 十有八九错误，立即离场 |

## 五、资金管理

### 5.1 仓位规则

| 规则 | 量化标准 |
|------|---------|
| **本金要求** | 每100股至少3000美元 |
| **单票风险** | 不超过总本金10% |
| **分散持仓** | 4~5只不同板块股票，均分资金 |
| **连续亏损** | 2~3次亏损后，减少至剩余本金10%交易 |
| **利润复投** | 利润=本金时，交易量可翻倍 |
| **备用金** | 积累大量利润后建立备用金保护安全 |

### 5.2 金字塔加码规则

| 股价区间 | 加码间距 | 加码比例 |
|---------|---------|---------|
| 20~50点 | 每5点加码一次 | 100→100→100→50→30→20 |
| 80~200点 | 每10点加码一次 | 同上递减 |
| 第4~5次加码后 | — | 每次数量减半 |

> **金字塔铁律**：第一笔交易亏损绝不加码。永不摊平损失。

## 六、波段操作 —— 江恩的盈利核心

> 江恩通过克莱斯勒1925~1935年的实际数据证明：波段操作远胜于长期持有。

### 6.1 波段操作规则

| 规则 | 量化标准 |
|------|---------|
| **最小波段幅度** | 8点及以上 |
| **波段利润目标** | 波段幅度的25%~50% |
| **克莱斯勒实证** | 10年57次≥8点的波段，总计1076点波动 |
| **50%捕获率** | 可获538点利润，远超直线持有 |

### 6.2 行情四阶段理论

江恩发现：任何牛市或熊市通常分**3~4个阶段**运行。

| 阶段 | 牛市特征 | 操作 |
|------|---------|------|
| **第一阶段** | 趋势启动，涨幅较小 | 轻仓试错 |
| **第二阶段** | 趋势加速，成交量放大 | 正常仓位+金字塔加码 |
| **第三阶段** | 涨势延续，成交量开始缩 | 警惕，准备减仓 |
| **第四阶段** | 最后一波，往往最猛烈 | **最重要**——第4次创新高往往是顶部 |

> **第四阶段是最重要的等待趋势变化的阶段。**

## 七、日/周/月线图分析流程

### 7.1 三时间框架分析

| 时间框架 | 作用 | 优先度 |
|---------|------|--------|
| **月线图** | 检测主趋势（最佳图表） | ⭐⭐⭐⭐⭐ |
| **周线图** | 仅次于月线图 | ⭐⭐⭐⭐ |
| **日线图** | 快速变化+大成交量时使用 | ⭐⭐⭐ |

### 7.2 标准分析步骤

**第一步：绘制月线图**
- 标记每月最高价和最低价
- 连接底部形成上升/下降趋势线
- 识别关键历史支撑和阻力（10~20年记录）

**第二步：叠加成交量**
- 在月线图上标注每月成交量
- 识别顶部巨量和底部缩量

**第三步：时间周期分析**
- 从重要顶/底起算关键时间节点（30/60/90/120/180天，1/2/3/5/7/10年）
- 关注关键季节日期（3/21、6/22、9/23、12/22等）

**第四步：50%和中点分析**
- 计算极限高低点之间的中点
- 标记1/4、1/2、3/4、5/8、7/8阻力位

**第五步：角度线（进阶）**
- 从重要底部绘制45°角度线（每月1点速率）
- 从重要顶部绘制向下45°角度线
- 观察角度线的支撑/压力效果

**第六步：交叉验证，做出操作决策**

## 九、与趋势交易系统的关系

> 江恩选股系统与现有趋势交易Skill（trend-trading）是**互补关系**，而非替代关系。

| 维度 | 趋势交易Skill | 江恩选股Skill | 协同使用 |
|------|-------------|-------------|---------|
| **趋势判断** | 均线多头排列+250日线 | 累进式底部+突破前高 | 双重验证趋势方向 |
| **入场时机** | 回踩5日线/20日线±2% | 3点回调+双底+50%位 | 取共振点入场 |
| **止损** | -7%或跌破20日线 | 1~3点（约-3%至-5%） | 江恩更紧，趋势更宽 |
| **成交量** | 缩量≤70%+放量≥150% | 顶部巨量+底部极缩 | 江恩提供补充验证 |
| **时间周期** | 横盘≥10日 | 2~3天/周/月+年度周期 | 叠加使用增强可靠性 |
| **板块轮动** | 板块共振判断 | 领涨/领跌股识别 | 协同筛选 |

**协同原则**：
- 趋势Skill定方向（大势），江恩Skill定节奏（入场时机+精确止损）
- 两者信号共振时：最高置信度操作
- 两者信号矛盾时：以趋势Skill方向为主，江恩Skill用于验证和细化

## 十、使用方式

当用户提出以下问题时，调用本Skill：

1. **"这只股票能不能买？"** → 用第八章评分卡打分 + 检查否决项
2. **"什么时候入场？"** → 对照第三章六种买入模式
3. **"止损设在哪？"** → 参照第一章3点法则+价格区间适配

9. **"什么时间容易变盘？"** → 用第二章2.5时间周期+关键日期
10. **"50%位置怎么用？"** → 用第二章2.3的50%规则
