# 日本蜡烛图技术分析

基于史蒂夫·尼森《日本蜡烛图技术》(第二版)提炼的可执行技术分析框架。

## 使用方式

1. **识别形态时**：参考下方核心形态速查表进行形态匹配
2. **做交易决策时**：严格遵循"多技术共同参照原则"，蜡烛图信号必须得到西方工具验证
3. **需要详细参数时**：读取 `references/candlestick_patterns_full.md` 获取每个形态的完整定义

---

## 核心原则

### 蜡烛图信号的金科玉律

1. **反转形态≠立即反转** — 趋势可能仅转为横向整理
2. **蜡烛图不提供价格目标** — 必须借助西方技术分析工具
3. **蜡烛图信号方向必须与主要趋势方向一致**时方可开新仓
4. **总体技术图像比单根蜡烛线重要** — 形态在图表中的位置决定其有效性
5. **必须结合风险报偿比**和止损计划
6. **多技术信号汇聚在同一价位**时反转概率最大

### 蜡烛线基本结构

| 组成部分 | 定义 |
|---------|------|
| 实体 | 开市到收市区间，阳线(白)=收>开，阴线(黑)=收<开 |
| 上影线 | 实体上方细线，顶端=最高价 |
| 下影线 | 实体下方细线，底端=最低价 |
| 纺锤线 | 实体极小，暗示趋势动能消退 |
| 十字线 | 开≈收，最重要的单线反转警告 |

### 实体与影线的市场含义

- **长实体**：单边行情主导，动量强
- **短实体(纺锤线)**：趋势动能消退，多空犹豫
- **长下影线**：日内空方一度占优但被多方完全反攻
- **长上影线**：日内多方一度占优但被空方完全反攻
- **十字线**：多空力量完全均衡，趋势可能生变

## 反转形态速查

### 单蜡烛线反转形态

| 形态 | 趋势前提 | 结构特征 | 信号 |
|------|---------|---------|------|
| **锤子线** | 下降趋势后 | 小实体在顶端，下影线≥实体2倍，无/短上影 | 🟢看涨底部 |
| **上吊线** | 上升趋势后(历史新高更佳) | 同锤子线，但需次日验证 | 🔴看跌顶部 |
| **流星线** | 上升趋势后 | 小实体在底端，长上影，无/短下影 | 🔴看跌顶部 |
| **倒锤子线** | 下降趋势后 | 同流星线，需次日收于其实体上方确认 | 🟢看涨底部 |
| **捉腰带线(白)** | 低价区 | 开市=最低价的长白实体 | 🟢看涨底部 |
| **捉腰带线(黑)** | 高价区 | 开市=最高价的长黑实体 | 🔴看跌顶部 |

### 双蜡烛线反转形态

| 形态 | 结构 | 信号 |
|------|------|------|
| **看涨吞没** | 下降趋势→小黑实体被后面大白实体完全覆盖 | 🟢看涨底部 |
| **看跌吞没** | 上升趋势→小白实体被后面大黑实体完全覆盖 | 🔴看跌顶部 |
| **乌云盖顶** | 上升趋势→长白实体→次日开>前高但收<白实体50% | 🔴看跌顶部 |
| **刺透形态** | 下降趋势→长黑实体→次日开<前低但收>黑实体50% | 🟢看涨底部 |
| **看涨反击线** | 下降趋势→长黑实体→次日开低走回收于前收市价 | 🟢看涨底部 |
| **看跌反击线** | 上升趋势→长白实体→次日开高走低收于前收市价 | 🔴看跌顶部 |
| **孕线** | 长实体后跟小实体(完全被包含)→趋势停顿 | ⚠️弱反转 |
| **十字孕线** | 孕线中子线为十字线→比常规孕线强 | 🔴🟢强反转 |

**关键判断标准**：
- 乌云盖顶和刺透形态的**50%穿入规则**是硬性标准
- 吞没形态只需实体覆盖，不需覆盖影线
- 孕线只看实体包含关系，影线可以超出

### 星线系列（三蜡烛线反转形态）

星线定义：小实体(可阳可阴)，与前一根较大实体之间存在价格跳空(实体不重叠)

| 形态 | 结构 | 信号 |
|------|------|------|
| **启明星** | 长黑→向下跳空小星→长白刺入黑实体 | 🟢看涨底部 |
| **黄昏星** | 长白→向上跳空小星→长黑刺入白实体 | 🔴看跌顶部 |
| **十字启明星** | 启明星的星线为十字线 | 🟢🟢更强看涨 |
| **十字黄昏星** | 黄昏星的星线为十字线 | 🔴🔴更强看跌 |
| **弃婴底** | 十字启明星+影线完全跳空 | 🟢🟢极强看涨 |
| **弃婴顶** | 十字黄昏星+影线完全跳空 | 🔴🔴极强看跌 |

### 其他多蜡烛线反转形态

| 形态 | 结构要点 | 信号 |
|------|---------|------|
| **平头顶/底** | 两线同高点(顶)或同低点(底)，需其他信号配合 | ⚠️弱信号 |
| **三只乌鸦** | 高价区连续三根依次下降的长黑线 | 🔴看跌顶部 |
| **白三兵** | 低价区连续三根依次上升的长白线 | 🟢看涨底部 |
| **向上跳空两只乌鸦** | 上升趋势→长白→向上跳空小黑→包住第二根的黑线 | 🔴看跌(罕见) |
| **三山顶部(头肩顶)** | 三次冲击同一高价区回落 | 🔴主要顶部 |
| **三川底部(头肩底)** | 三次下探同一低价区反弹 | 🟢主要底部 |
| **圆形顶/平底锅底** | 小实体圆弧+最终窗口(跳空)确认 | 🔴/🟢反转 |
| **塔形顶/底** | 长实体→小实体整固→反向长实体 | 🔴/🟢反转 |

## 持续形态速查

持续形态完成后市场恢复原有趋势方向。

| 形态 | 结构要点 | 信号 |
|------|---------|------|
| **向上窗口** | 前高<当前低(影线不重叠) | 🟢看涨持续 |
| **向下窗口** | 前低>当前高(影线不重叠) | 🔴看跌持续 |
| **上升三法** | 长白→3根小实体整固(全在白线区间内)→长白突破 | 🟢看涨持续 |
| **下降三法** | 长黑→3根小实体整固(全在黑线区间内)→长黑突破 | 🔴看跌持续 |
| **高价位跳空突破** | 急涨→小实体整固→向上跳空 | 🟢看涨持续 |
| **低价位跳空突破** | 急跌→小实体整固→向下跳空 | 🔴看跌持续 |
| **跳空并列阴阳线** | 跳空后紧接反向线(罕见) | 窗口方向定论 |
| **分手线** | 同开市价的顺趋势线(罕见) | 顺趋势持续 |

**窗口核心原则**：
1. 窗口本身是首要信号，方向决定一切
2. 窗口转化为支撑(向上窗口)或阻挡(向下窗口)
3. 市场回补窗口("回填跳空")时，收市价穿越窗口边界才算有效突破
4. 趋势不受窗口数量影响，直到最后一个窗口被关闭

## 十字线 (Doji) 专题

十字线是最重要的单蜡烛线反转信号，代表市场"犹豫不决"。

### 关键特性

- **在上升趋势中揭示顶部反转**极其有效
- **在下降趋势中往往丧失反转潜力**——可能仅是中继
- **底部反转需要更多佐证**，除非验证了支撑水平
- **箱体区间中的十字线无预测意义**，除非位于区间边界

### 十字线分类

| 类型 | 特征 | 信号 |
|------|------|------|
| **北方十字线** | 上涨行情中 | 🔴看跌顶部警告 |
| **南方十字线** | 下跌行情中 | ⚠️通常不构成反转 |
| **长腿十字线** | 极长上下影线，小实体/十字 | 市场失去方向感 |
| **墓碑十字线** | 开/收=最低点，极长上影 | 🔴强看跌顶部 |
| **蜻蜓十字线** | 开/收=最高点，极长下影 | 🟢看涨信号 |
| **三星形态** | 三根十字线排列 | 🔴/🟢主要反转(罕见) |

### 十字线有效性判断

- 十字线前后有一系列小实体 → 不算十字线
- 在若干长蜡烛线之后出现 → 可视为十字线
- 处于重要转折点/超买超卖 → 可视为十字线
- **宁可错认，不可漏过**

## 多技术共同参照原则

> 核心概念：在同一位或接近价位上出现一群相互验证的技术信号 → 反转可能性显著增大。

### 与趋势线结合

- 蜡烛图形态在趋势线处出现 → 形态重要性加持
- 即使不理想的形态+趋势线验证 → 也具备信号价值
- **破低反涨(Spring)**：一度跌破支撑但无法维持→🟢看涨
- **破高反跌(Upthrust)**：一度突破阻挡但无法维持→🔴看跌
- **极性转换原则**：过去的支撑→新的阻挡；过去的阻挡→新的支撑

### 与百分比回撤结合

- 常用回撤水平：38.2%、50%、61.8%（斐波那契）
- **核心原则**：不能仅在回撤水平处买卖，必须等待蜡烛图信号验证

### 与移动平均线结合

- 常用参数：5日、9日、20日、30日、50日、200日
- MA从支撑被跌破后转为阻挡，反之亦然(极性转换延伸)
- **核心原则**：以蜡烛图信号验证MA的支撑/阻挡→然后建仓/平仓
- 黄金交叉(短期上穿长期)→看涨；死亡交叉(短期下穿长期)→看跌

### 与摆动指数结合

- **超买/超卖仅为警告信号**，需要蜡烛图形态提供最终确认
- RSI>70%超买+乌云盖顶/黄昏星 → 相互验证→做空
- RSI<30%超卖+刺透形态/启明星 → 相互验证→做多
- 背离(顶背离/底背离)+蜡烛图反转信号 → 高概率转折

### 与交易量结合

- 看涨吞没：第一根(纺锤线)量轻+第二根(长白)量重 → 看涨强度加倍
- 乌云盖顶第二天开市时量极大("胀爆") → 顶部概率增加
- 纺锤线/十字线+巨大交易量 → 极端行情后的反转预警
- "涨爆现象"：极高量+长实体 → 极端行情结束信号

### 测算价格目标

- 箱体突破：突破方向 + 箱体高度 = 价格目标
- 对等运动：第一波高度叠加到调整低点/高点上
- 旗形/三角旗形：旗杆高度 + 旗帜边界 = 目标
- 蜡烛图提供入市信号，西方工具提供出市目标

## 交易纪律

1. **先评估风险报偿比**，再根据蜡烛图信号下单
2. **始终设置保护性止损**，在初始交易时同时设定
3. **宁可放弃观点，不可赔掉金钱**
4. **不做趋势预测者，做趋势追随者**
5. **保住本金是第一要务**
6. 蜡烛图信号方向必须与主要趋势方向一致

## 形态优势分级（自上而下）

| 级别 | 形态类型 | 说明 |
|------|---------|------|
| ⭐⭐⭐⭐⭐ | 弃婴顶/底、三星形态 | 极罕见，一旦出现极其可靠 |
| ⭐⭐⭐⭐ | 十字黄昏星/启明星、吞没形态+量验证 | 强反转信号 |
| ⭐⭐⭐ | 黄昏星/启明星、乌云盖顶/刺透、三山三川 | 标准强反转 |
| ⭐⭐ | 锤子/上吊/流星/倒锤、孕线、平头形态 | 需要验证信号 |
| ⭐ | 单根纺锤线、窗口内的十字线 | 警告信号，不构成交易依据 |
