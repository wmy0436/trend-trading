# 缠论（缠中说禅）实战交易系统

> 来源：《一小时漫画缠论实战法》（管鹏 著/绘，人民邮电出版社 2022.4）
> 缠论是一套完全适用于A股市场的原创技术分析体系，技术面分析严谨，答案唯一，
> 不像道氏理论因人而异和"千人千浪"。核心思想：**把行情走势分类，结合不同级别
> 的时间周期，做到不测而测。**

---

## 一、缠论核心哲学

### 1.1 基本理念
- 缠论的本质是科学——包含交易心理学、形态学原理
- 市场走势无非六种可能性，分类后买卖点就清楚了
- **走势必完成**：一个级别的走势一定会完成——这是股市不确定性中的确定性
- 绝对的**右侧交易**：哪怕预测确定了高低点，也要等信号出现后再操作
- 技术面分析 = 在无序市场中建立有序排列的结构，用数学递归方式找出级别

### 1.2 两大分析维度
| 维度 | 内容 |
|------|------|
| 基本面 | 行业现状、财务数据、国家政策、市值地位、板块形势、股价位置 |
| 技术面 | K线→分型→笔→线段→中枢→走势类型→级别→背驰→买卖点 |

### 1.3 适用品种与周期
- 适用任何金融品种，尤其在A股市场
- 支持所有周期：超短线(1m/5m)、短线(30m)、中线(日线)、长线(周线/月线)
- **只看**: 1分钟、5分钟、30分钟、日线、周线、月线（不看15分/60分）

## 二、K线、包含处理与分型

### 2.1 缠论K线定义
缠论K线与传统K线不同——**只看股价到达的价格区间**（最高点与最低点），不重视
开盘价、收盘价、上影线、下影线。

**如何确定缠论K线**：找到该周期内的最高点(H)和最低点(L)。

### 2.2 四种分型
| 分型 | 定义 | 方向含义 |
|------|------|----------|
| **上升K线** | 出新高、不出新低 | ⬆ 向上 |
| **下降K线** | 出新低、不出新高 | ⬇ 向下 |
| **顶分型** | 中间高，两边低，形似"品"字 | 顶部形成，将转下降 |
| **底分型** | 中间低，两边高，形似倒"品" | 底部形成，将转上升 |

**顶分型的严格定义**：三根相邻K线，中间K线的高点是三根中最高的，
中间K线的低点也是三根中最高的。
**底分型的严格定义**：三根相邻K线，中间K线的低点是三根中最低的，
中间K线的高点也是三根中最低的。

### 2.3 K线包含处理（必须严格执行）

**触发条件**：两根相邻K线，一根被另一根完全包含（一根的H和L都在另一根的H和L范围之内）。

**合并规则**：
1. **先判断方向**：看发生包含前的分型走势是上升还是下降
2. **上升趋势中的包含**：取两根K线的 **最高高点** 和 **最高低点** 合并为新的K线
3. **下降趋势中的包含**：取两根K线的 **最低高点** 和 **最低低点** 合并为新的K线
4. **多根K线连续包含**：从左到右依次处理，处理完一对再看下一对

**口诀**：上升取高高，下降取低低。先判断方向，再依次合并。

### 2.4 分型的确立
- 经过包含处理后，连续三根不互相包含的K线即可判断分型
- 顶分型和底分型交替出现
- 只有经过包含处理后的标准K线才能参与分型判定

## 三、笔（最小分析单元）

### 3.1 笔的定义
笔是缠论中最小的分析单元，像一个阶段的走势画线。由三个部件组成：

```
顶分型 + 中间K线 + 底分型
```

### 3.2 笔的两种方向
| 方向 | 结构 | 特征 |
|------|------|------|
| **上升笔** | 底分型 → 上升K线 → 顶分型 | 低到高 |
| **下降笔** | 顶分型 → 下降K线 → 底分型 | 高到低 |

### 3.3 笔的严格规则（五条铁律）
1. **顶底必须对应**：顶分型只配对底分型，绝不出现"底分型→底分型"或"顶分型→顶分型"
2. **没有平行笔**：笔只有上升和下降两个方向
3. **中间K线最少1根**：不属于顶分型和底分型的独立K线至少一根
4. **至少5根K线**：一笔最少由5根K线组成（顶分型3根+底分型3根，中间共用1根，最少独立1根 = 5根）
5. **笔是连续的**：上升笔结束紧跟下降笔，下降笔结束紧跟上升笔；永不隔空跳笔

### 3.4 笔的确认时机
- 一根笔不能自我确认结束
- **新笔的出现才确认上一笔的完成**
- 新笔出现 = 已出现至少5根K线形成反向分型
- 新笔出现后也不能被确认，要等更新的笔出现才能确立

### 3.5 画笔实用技巧
- 熟练后看走势即可快速画笔，无需逐根数K线
- 只要笔不是太短，一般不需严格数包含
- 只有五六根K线时才需要仔细数包含关系
- **一两根笔的位置偏差不影响整个级别的走势判断**

## 四、线段

### 4.1 线段定义
线段由笔组成。**最少由三笔组成，且三笔在价位上必须有重叠部分。**

级别关系：K线(兵) → 分型(班) → 笔(排) → **线段(连)** → 走势(营)

### 4.2 线段的方向
- **向上线段**：起始于向上笔，终结于向上笔
- **向下线段**：起始于向下笔，终结于向下笔
- **没有横向线段**
- 永远的规则：向上线段不会始于向下笔终于向上笔

### 4.3 线段的终结
- 向上线段的终结 = 出现新的向下线段来确立
- 如果没有出现反向线段，原线段会一直延续
- 原因：趋势没走完，线段本身是体现趋势的

### 4.4 笔与线段的关系
- 大级别的一笔 ≈ 小级别的一条线段
- 在5分钟图上画线段 = 在30分钟图上画笔
- 笔中枢和线段中枢不在一个级别
- 由 **9根或9根以上笔** 构成的笔中枢自动升级为线段中枢

## 五、中枢（核心中的核心）

### 5.1 中枢的本质
中枢就是筹码密集区，是多空力量博弈的集中体现。
- 你来我往的时间越长 → 能量越大 → 爆发的走势越强
- 中枢结束后会有一段行情的延续

### 5.2 中枢的画法（以线段中枢为准）

**步骤**：
1. **先判断方向**：看最初线段的方向
2. 一个完整中枢至少看 **5根线段**：进入段(1) + 中枢(至少3根) + 走出段(1)
3. 进入段和走出段方向必须一致（决定中枢方向）
4. 取中间所有线段 **互相重叠的部分** 作为中枢本体

### 5.3 中枢的结构类型

| 中枢类型 | 方向 | 结构 | 结束规则 |
|----------|------|------|----------|
| **上升中枢** | ⬆ | 下-上-下（始终以下结束） | 下-上-下-上...最后以下-上-下结束 |
| **下降中枢** | ⬇ | 上-下-上（始终以上结束） | 上-下-上-下...最后以上-下-上结束 |

### 5.4 中枢关键点位
以中枢中 **前三根线段** 为参考：
- **ZG（中枢高点）** = 前三线段中各线段高点中的 **最低点**
- **ZD（中枢低点）** = 前三线段中各线段低点中的 **最高点**
- 中枢区间 = [ZD, ZG]

### 5.5 笔中枢
- 笔中枢画法与线段中枢相同，只是把线段替换成笔
- 更直观、方便快速识别
- 走势不清时缩小级别，走势太乱时放大级别

### 5.6 特殊中枢——奔走中枢
- 重合部分特别少的中枢
- 压制力量小，被原有力量瞬间秒杀
- 原走势会非常强势
- **容易遗漏，但对买卖点很重要**

### 5.7 中枢完成的确认
走出段走出中枢后，又出现一个线段**没有回到中枢区间内**，
则中枢确认完成。这个回不到中枢的点就是——**第三类买卖点**。

## 六、走势类型

### 6.1 两大走势类型
缠论中没有横向走势，只有上升和下降！

| 类型 | 包含中枢数 | 细分 |
|------|-----------|------|
| **盘整走势** | 1个中枢 | 上升盘整 / 下降盘整 |
| **趋势走势** | ≥2个同级别、同方向中枢 | 上升趋势 / 下降趋势 |

### 6.2 趋势走势的严格条件
1. 至少 **两个** 中枢
2. 两个中枢必须是 **同级别**
3. 两个中枢必须是 **同方向**
4. 两个中枢之间 **不能有重合部位**（否则合并为一个中枢 → 中枢扩张）

### 6.3 走势命名（a-A-b-B-c 命名法）
```
a = 趋势的进入段
A = 第一个中枢
b = A的走出段 / B的进入段
B = 第二个中枢
c = B的走出段
```
盘整走势只有 a-A-b 三个阶段。

### 6.4 走势必完成
**一个趋势走到c就差不多了**，不建议追高，随时可能下跌。
走势很少有走到C、d阶段——这由人类交易习性决定。
但走势也可能生长，小级别生长为大级别。

## 七、级别

### 7.1 级别的双重含义

| 含义 | 具体 |
|------|------|
| **时间周期级别** | 1分钟 > 5分钟 > 30分钟 > 日线 > 周线 > 月线 |
| **形态级别** | 笔 < 线段 < 走势（同一时间周期内） |

### 7.2 级别升级规则
1. 走势的级别由 **最初开始的K线图级别** 确定
2. 在1分钟图开始的走势 → 1分钟级别走势
3. 1分钟级别走势完成 → 升级到5分钟级别
4. 以 **线段走势的完成** 作为级别升级的条件
5. 即使1分钟走势走了几个月，在月线中都快成一笔了，仍是1分钟级别

### 7.3 级别换算关系
- 5分钟图上的一根K线 = 1分钟图上的5根（≈一笔）
- 1分钟图上的一个线段 ≈ 5分钟图上的一笔
- 30分钟图上的完整走势 ≈ 日线图上的一根线段
- 日线图里的线段 ≈ 周线图里的笔

### 7.4 交易级别选择
- **短线**：30分钟K线图（推荐新手起点）
- 往小看5分钟/1分钟 → 看清走势细节（区间套）
- 往大看日线/周线 → 知道当下大位置
- **交易决策只按一个级别**：按什么级别买就按什么级别卖
- 不可30分钟买点买入，5分钟卖点卖出

### 7.5 为何不看15分钟和60分钟
- 15分钟图的一根K线在5分钟图里只有3根，不足5根无法构成一笔
- 60分钟图的一根K线在日线里只有4根，无法构成最小分析单元

## 八、背驰

### 8.1 背驰的核心意义
**用来判断一个走势是否快要走完了**。出现背驰 = 走势呈衰弱趋势，可能即将完结，
可以开始找买卖点。

### 8.2 三种背驰判断方法

#### 方法一：MACD红绿柱面积比较
- 在中枢的进入段(a)和走出段(b/c)之间比较
- 取MACD红绿柱最高拐点处的面积×2大致估算
- 面积缩小 = 背驰

#### 方法二：绝对长度比较
- 直接比较进入段和走出段的**绝对长度（真正走出中枢的长度）**
- 走出段越来越短 → 脱离中枢的力量越来越弱 → 背驰
- **推荐与MACD结合使用**

#### 方法三：成交量
- 成交量缩小可能指示背驰
- 但涨停板组成的上涨段成交量无参考意义
- 缠论体系中对成交量不太看重

### 8.3 背驰的判断规则
- b的长度 < a的长度 → B走完后走势随时可能完成 → 不建议确定买卖点（风险较大）
- b没有背驰 → B完成后c可能走得更远
- c也没有背驰 → 可能出现C、d
- 一般来说走势走到c就完结了，很少有C、d

### 8.4 关键注意事项
1. **只在a、b、c之间比较**，不与中枢内的线段/笔比较
2. 本来背驰了却与中枢内线段比较 → 误判为无背驰 → 重仓买入即被套
3. 必须在走势分析基础扎实之后才谈背驰

## 九、区间套

### 9.1 区间套的本质
从小级别往大级别找走势的过程 = **区间放大镜**。大级别拿出一根线段，在小级别
中可能就是一个完整的走势。

### 9.2 区间套判断背驰的步骤
以判断30分钟级别的b是否背驰为例：

1. 识别：30分钟图走势走到b
2. 放大：把b放到5分钟图上，看5分钟级别的完整走势
3. 判断：
   - 若b在30分钟图已走得和a差不多高，且在5分钟图也丝毫没有完结 → **不背驰**
   - 若b在30分钟图没走多远，5分钟图走势已走到c即将完结 → **已背驰**
   - 若5分钟图走势也走到b → 继续放大到1分钟图判断

### 9.3 区间套定位买卖点
- 大级别的买点/卖点都是小级别的一买/一卖
- 用区间套确认：大级别即将到买点 → 看小级别 → 等小级别一买出现
- **必须等小级别一买确立**（二买出现=一买确立），才能在大级别交易

## 十、三类买卖点（三买三卖）

### 10.1 三类买点

| 买点 | 发生位置 | 确立条件 | 风险/收益 |
|------|----------|----------|-----------|
| **一买** | 下降走势完结后的转折点 | 由下降走势背驰引发；二买出现后确立 | 风险最大，最难抓，易抄在半山腰 |
| **二买** | 一买后上涨回落的低点 | 不跌破一买位置 | 较安全，适合入场 |
| **三买** | 中枢走完后回踩不进入中枢 | 必须不进入中枢区间 | **最重要！** 排除盘整，只赚趋势的钱 |

### 10.2 三类卖点（完全对称）
| 卖点 | 发生位置 | 确立条件 |
|------|----------|----------|
| **一卖** | 上升走势完结后的转折点 | 由上升走势背驰引发 |
| **二卖** | 一卖后下跌反弹的高点 | 不升破一卖位置 |
| **三卖** | 中枢走完后反弹不进入中枢 | 必须不进入中枢区间 |

### 10.3 买卖点使用建议
- **一买一卖最难掌握，不建议新手参与**
- 二买/二卖可以下手
- **三买三卖是赚钱核心，必须参与**
- 仓位分配建议：一买1成 + 二买3成 + 三买6成
- 新手操作30分钟及以上级别，太小级别涨幅小且易错过

### 10.4 盘整vs趋势的处理
- 盘整走势可出现一买、二买，**无三买**就掉头完结走势
- 三买的意义 = **排除盘整走势的个股** → 锁定趋势走势 → 赚趋势的钱

### 10.5 二三类买点重合
下降走势完结后上升异常凶猛，二买位置已在原走势中枢之上 → **二买三买重合**，
同时买入，即使盘整也有利润。

## 十一、结合律与多义性

### 11.1 结合律的数学法则
```
a+b+c = (a+b)+c = a+(b+c)
但 a+b+c ≠ (a+c)+b
```

### 11.2 结合律的核心规则
1. **组件独立**：任何组件不能重复使用
2. **顺序结合**：必须按先后顺序结合，不能跳过中间结构
3. **走势完整**：可以合并的走势必须是完整走势的合并
4. **不可局部合并**：不可能是两个走势的局部合并

### 11.3 结合律在走势划分中的应用
- 中枢走完继续上涨 → 原走势未结束 → 要合并 → 走势生长了
- 中枢走完向下走 → 是新的走势的一部分 → 不能合并
- **确定依据**：第三类买卖点的出现

### 11.4 多义性
- 满足结合律和所有知识点的前提下，走势可以有多种划分方式
- **无论怎么划分，买卖点都不变** —— 这是结合律的最大特征
- 多义性 = 不预测，只分类 → 根据三买三卖确认操作

### 11.5 走势预测的方式
根据多义性总结几种可能的走势 → 根据市场环境、利好利空适当预测 →
**根据第三类买卖点的出现来确定走势** → 做到不测而测

## 十二、缠论实战分析流程

### 12.1 标准化分析步骤

```
Step 1: 确定分析周期
  └─ 选30分钟或日线为主级别
  └─ 同时关注小区间套级别(5分钟)和大级别(日线/周线)

Step 2: K线包含处理
  └─ 从第一根K线开始，从左到右处理所有包含关系
  └─ 形成标准K线序列

Step 3: 识别分型
  └─ 在标准K线序列中标记顶分型和底分型
  └─ 确保顶底交替

Step 4: 画笔
  └─ 按顶底对应原则连接分型
  └─ 确保每笔至少5根K线
  └─ 新笔出现确认旧笔完成

Step 5: 画线段
  └─ 至少三笔有重叠构成线段
  └─ 注意线段方向

Step 6: 画中枢
  └─ 先判断整体方向
  └─ 取进入段和走出段之间的至少3根线段的重叠部分
  └─ 标记ZG、ZD

Step 7: 判断走势类型
  └─ 1个中枢 → 盘整走势
  └─ ≥2个同向同级中枢 → 趋势走势
  └─ 走势命名：a-A-b-B-c

Step 8: 分析背驰
  └─ 比较a/b/c的MACD面积或绝对长度
  └─ 用区间套放大确认

Step 9: 定位买卖点
  └─ 一买一卖：走势完结转折点（新手回避）
  └─ 二买二卖：回调不破前低/反弹不过前高
  └─ 三买三卖：出中枢后回踩不回中枢（重点参与）

Step 10: 执行交易
  └─ 按选定级别操作
  └─ 什么级别买就什么级别卖
  └─ 仓位递进：1成→3成→6成
```

### 12.2 每日/每周检查清单

**走势状态检查**：
- [ ] 当前是什么走势类型？（盘整/趋势，上升/下降）
- [ ] 走势走到哪个阶段了？（a/A/b/B/c？）
- [ ] 背驰出现了吗？
- [ ] 三买/三卖出现了吗？

**级别检查**：
- [ ] 大级别（日线/周线）目前处于什么走势？
- [ ] 操作级别是否一致？
- [ ] 小级别走势是否支持大级别判断？

**买卖点检查**：
- [ ] 当前是否有明确的买卖点信号？
- [ ] 是哪一类买卖点？
- [ ] 是否已用区间套确认？

## 十三、重要原则与风险提示

### 13.1 缠论的边界
- 建议不要做日线级别以下的操作（仅限入门阶段）
- 多从基本面着手，缠论只是帮你厘清思路、找出买卖点的工具
- **投资还是要靠心**

### 13.2 常见误区
1. **级别混淆**：不同级别混着买卖 ← 最致命错误
2. **背驰误判**：与中枢内部比背驰而不是与a、b、c比较
3. **急于操作**：不等三买确认就追入
4. **忽略结合律**：组件重复使用导致走势划分错误
5. **忘记右侧交易**：预测顶底后不等信号就操作

### 13.3 建议学习路径
1. 先学会画笔和线段（基本功）
2. 掌握中枢画法（重中之重）
3. 理解走势类型和级别
4. 学会背驰判断和区间套
5. 练习三买三卖的识别
6. 从大级别（日线/周线）开始实盘练习
7. 熟练后再尝试小级别操作
