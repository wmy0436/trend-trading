# 缠论量化规则速查表

> 将缠论所有规则转化为可量化、可编程的判断条件

---

## 一、K线包含处理量化

### 输入
两根相邻K线：K1(H1, L1)，K2(H2, L2)

### 包含判断
```
K1包含K2: H1 >= H2 AND L1 <= L2
K2包含K1: H2 >= H1 AND L2 <= L1
包含成立: (H1>=H2 AND L1<=L2) OR (H2>=H1 AND L2<=L1)
```

### 合并算法
```
已知前一分型的走势方向为direction（上升=1，下降=-1）

IF direction == 1（上升趋势中）:
    新K线: H_new = MAX(H1, H2)
            L_new = MAX(L1, L2)

IF direction == -1（下降趋势中）:
    新K线: H_new = MIN(H1, H2)
            L_new = MIN(L1, L2)
```

### 多根包含处理
```
从左到右依次处理：
WHILE 存在相邻K线包含:
    取最左边一对包含的K线
    根据前一分型方向合并
    用合并后的新K线替换这两根
    继续检查
```

## 二、分型量化判断

### 顶分型
```
三根连续K线 K1, K2, K3 构成顶分型：
条件1: K2.H > K1.H AND K2.H > K3.H  （K2的高点是三根中最高的）
条件2: K2.L > K1.L AND K2.L > K3.L  （K2的低点是三根中最高的）
条件3: K1, K2, K3 互不包含
```

### 底分型
```
三根连续K线 K1, K2, K3 构成底分型：
条件1: K2.L < K1.L AND K2.L < K3.L  （K2的低点是三根中最低的）
条件2: K2.H < K1.H AND K2.H < K3.H  （K2的高点是三根中最低的）
条件3: K1, K2, K3 互不包含
```

## 三、笔的量化规则

### 笔的构成条件（五条铁律）
```
1. 顶底对应:  笔两端的K线一个是顶分型的中间K线，一个是底分型的中间K线
2. 方向唯一:  只有上升笔(底→顶) 和 下降笔(顶→底)
3. 中间K线:   两分型之间至少有1根不属于任何分型的独立K线
4. 最少K线数: 从起点分型第一根K线到终点分型最后根K线 >= 5根
5. 连续交替:  上升笔后必须接下降笔，下降笔后必须接上升笔
```

### 笔的确认
```
一笔的结束标记: 出现反向的至少5根K线构成的反向分型
一笔的确认: 更新的一笔出现后，该笔才被确认
```

### 上升笔量化
```
上升笔 = 底分型[三根K线，以中间K线低点为笔的起点]
         + 中间K线[至少1根独立K线]
         + 顶分型[三根K线，以中间K线高点为笔的终点]
```

### 下降笔量化
```
下降笔 = 顶分型[三根K线，以中间K线高点为笔的起点]
         + 中间K线[至少1根独立K线]
         + 底分型[三根K线，以中间K线低点为笔的终点]
```

## 四、线段量化规则

### 线段构成条件
```
1. 包含至少3笔
2. 这3笔在价位上有重叠（三笔的价格区间有交集）
3. 线段方向:
   - 向上线段: 第1笔是上升笔，最后1笔也是上升笔
   - 向下线段: 第1笔是下降笔，最后1笔也是下降笔
```

### 线段终结条件
```
向上线段终结: 出现一条新的向下线段
向下线段终结: 出现一条新的向上线段
```

### 笔与线段转换
```
在较小级别图上:  一条线段
在较大级别图上:  ≈ 一笔
9笔以上的笔中枢 → 升级为线段中枢
```

## 五、中枢量化规则

### 中枢定义
```
中枢由至少3根线段（或笔）组成
位置: 进入段之后，走出段之前
进入段与走出段方向一致

上升中枢: 进入段=上升 → 中枢=下-上-下 结构
下降中枢: 进入段=下降 → 中枢=上-下-上 结构
```

### 中枢区间计算
```
取前三根线段作为参考:
ZG = MIN(线段1.高点, 线段2.高点, 线段3.高点)   -- 高中取低
ZD = MAX(线段1.低点, 线段2.低点, 线段3.低点)   -- 低中取高

中枢区间 = [ZD, ZG]
```

### 中枢完成确认
```
条件: 走出段出中枢后，出现一根线段
判断: 这根线段的端点是否回到中枢区间[ZD, ZG]内
结果: 不回到 → 中枢完成（该点即第三类买卖点）
      回到 → 中枢延续/扩张
```

### 中枢扩张
```
两个同向中枢的区间出现重合 → 合并为一个更大的中枢
判断: 中枢2的[ZD, ZG] 与 中枢1的[ZD, ZG] 有交集
```

### 奔走中枢识别
```
特征: ZG - ZD 的幅度极小（重合区域很小）
含义: 原来的力量极强，瞬间击穿中枢
```

## 六、走势类型量化

### 盘整走势
```
条件: 完整走势中恰好包含1个中枢
上升盘整: a(上升) + A(中枢) + b(上升)
下降盘整: a(下降) + A(中枢) + b(下降)
```

### 趋势走势
```
条件1: 包含至少2个中枢
条件2: 两个中枢同方向
条件3: 两个中枢同级别（笔中枢vs笔中枢 或 线段中枢vs线段中枢）
条件4: 两个中枢无重合
```

### 同级别中枢判断
```
1. 肉眼比较: 两个中枢大小（ZG-ZD的幅度）差不多
2. 组件一致: 都是笔中枢 或 都是线段中枢
3. 笔中枢: 构成的笔数差不多
4. 笔中枢与线段中枢不在一个级别
```

### 走势命名（a-A-b-B-c法则）
```
趋势命名:
a = 整个趋势的初始进入段
A = 第一个中枢
b = 连接段（A的走出段 = B的进入段）
B = 第二个中枢
c = B的走出段（走势通常在此完结）

盘整命名:
a = 进入段
A = 中枢
b = 走出段
```

## 七、背驰量化判断

### MACD面积法
```
步骤1: 在中枢的进入段(a)和走出段(b/c)分别取MACD柱的最高拐点
步骤2: 估算该段MACD红绿柱的面积 = 最高拐点处面积 × 2（近似）
步骤3: 比较两段的面积

判断:
b段MACD面积 < a段MACD面积 → b对a背驰
c段MACD面积 < b段MACD面积 → c对b背驰
面积不缩小 → 无背驰 → 可能继续延伸
```

### 绝对长度法
```
定义: 绝对长度 = 走出中枢的价格幅度（不是线段总长度）
b绝对长度 < a绝对长度 → b对a背驰（最常用判断）
```

### 区间套确认法
```
判断b是否背驰:
1. 取b段在大级别(K线图)的表现
2. 到小级别(K线图)看b段内部的完整走势
3. 小级别已走完c → b背驰
4. 小级别还在a或b → b暂不背驰
5. 可递归到更小级别继续放大
```

### 背驰判断禁区
```
严禁与中枢内部线段/笔做比较！
正确: a vs b, b vs c
错误: A内部线段 vs b  ← 会导致严重误判
```

## 八、三类买卖点量化

### 一类买点（一买）
```
前提条件: 下降走势确认完成（走出段背驰+走势结构完成）
买点位置: 下降走势最后一个中枢的走出段结束点
确认条件: 二买出现 = 一买正式确立
风险等级: 高（容易抄在半山腰）
```

### 二类买点（二买）
```
前提条件: 一买之后股价已开始上涨
买点位置: 上涨后第一次回调的低点
确认条件: 回调低点 > 一买价位
风险等级: 中
最佳策略: 新手从此入手
```

### 三类买点（三买）
```
前提条件: 上升走势中，中枢已完成
买点位置: 中枢走出段后，回踩但未进入中枢[ZD, ZG]
确认条件: 回踩结束，价格在中枢上方企稳
重要意义: 排除盘整走势，确认趋势延续
风险等级: 中低
最佳策略: 必须参与！
```

### 三类卖点（完全对称反转）
```
一卖: 上升走势完成，背驰引发转折点 → 二卖确认
二卖: 一卖后下跌反弹的高点 < 一卖价位
三卖: 下降中枢回踩不进入中枢 → 确认下降趋势延续
```

### 二三类买卖点重合
```
条件: 二买/二卖位置已越过原有中枢
含义: 走势极强/弱
策略: 同时买入/卖出
```

## 九、级别换算速查

| 大级别 | = 小级别的什么 | 关系 |
|--------|---------------|------|
| 月线一笔 | 周线一条线段 | 月线笔 ≥ 周线线段 |
| 周线一笔 | 日线一条线段 | 周线笔 ≥ 日线线段 |
| 日线一笔 | 30分钟线段/走势 | 日线笔 ≥ 30分钟线段 |
| 30分钟一笔 | 5分钟线段 | 30分钟笔 ≥ 5分钟线段 |
| 5分钟一笔 | 1分钟线段/走势 | 5分钟笔 ≥ 1分钟线段 |
| 9笔笔中枢 | = 线段中枢 | 自动升级 |

### 时间周期K线换算
```
1分钟图5根K线 ≈ 5分钟图1根K线 ≈ 1分钟图上的1笔
5分钟图6根K线 ≈ 30分钟图1根K线
30分钟图8根K线 ≈ 日线图1根K线
日线图5根K线 ≈ 周线图1根K线
```

## 十、结合律量化规则

### 结合律公式
```
有效: a+b+c = (a+b)+c = a+(b+c)
无效: a+b+c ≠ (a+c)+b
```

### 结合律三个条件
```
1. 组件独立: 每个组件只能被使用一次，不可重复
2. 顺序结合: 只能按时间先后顺序，不可跳过
3. 走势完整: 合并的必须是完整走势，不是局部走势
```

### 中枢确认与结合律
```
中枢走完后: 
  第三类买点出现 → 新走势开始 → 不能与原走势合并
  回到中枢内 → 原走势未结束 → 中枢扩张/走势生长
```

## 十一、买卖点有效性检查清单

```
□ 当前走势类型已确认？（盘整/趋势）
□ 走势命名阶段已确定？（a/A/b/B/c）
□ 背驰条件已满足？（MACD面积 或 绝对长度 缩量）
□ 区间套已确认？（小级别支持大级别判断）
□ 买卖点类型正确？（一类/二类/三类）
□ 操作级别一致？（同一级别买卖）
□ 三买三卖的条件已满足？（出中枢未回中枢）
```

## 十二、技术分析工作流程（伪代码）

```
function 缠论分析(K线数据, 主级别):
    # Step 1: 包含处理
    标准K线 = 包含合并处理(K线数据)
    
    # Step 2: 分型识别
    分型列表 = 识别分型(标准K线)
    
    # Step 3: 画笔
    笔列表 = 画笔(分型列表)
    
    # Step 4: 画线段
    线段列表 = 画线段(笔列表)
    
    # Step 5: 画中枢
    中枢列表 = 画中枢(线段列表)
    
    # Step 6: 判断走势类型
    走势类型 = 判断走势(中枢列表)  # 盘整 或 趋势
    走势阶段 = 命名阶段(走势类型)  # a/A/b/B/c
    
    # Step 7: 背驰分析
    背驰结果 = 判断背驰(走势阶段)
    区间套确认 = 区间套验证(背驰结果, 小级别)
    
    # Step 8: 买卖点定位
    买卖点 = 定位买卖点(背驰结果, 中枢列表, 区间套确认)
    
    return {
        走势类型, 走势阶段, 背驰状态, 买卖点
    }
```
