# 选股执行检查清单

> 与 SKILL.md 的 6 步工作流一一对应。每步满足才进入下一步；带 ★ 为一票否决项。

---

## ★ 前置闸门（任一不满足 → 全场空仓观望）
- [ ] 大盘日线级别出现 W 底 / 双底 结构，或至少 30 分钟级别底背离
- [ ] 出现增量资金进场抄底（非单日脉冲）
- [ ] 底部出现放量大阳线 / 长下影确认
- 说明："大盘未见底前不做"——三者缺一，不入场。

## Step 1 — 判大势
- [ ] 当前牛/熊、什么级别已明确（月线无系统性风险）
- [ ] 大盘与候选板块方向同向（不同向则换板块或等）

## Step 2 — 定波浪位置
- [ ] 标的所处浪型已定位（一浪？二浪 C 浪回踩？三浪？五浪末？）
- [ ] 不在 B 浪反弹高位追入（等 C 浪回踩）
- [ ] 三浪目标 > 一浪前高；五浪末不买

## Step 3 — 选板块（对照 sector-view.md）
- [ ] 落在「看多」表内（底部/红利主线）
- [ ] 非「高位三兄弟」/ 科创50 / 恒生科技（这些只做反弹）
- [ ] 板块处于回踩未破支撑，非已大涨到压力位

## Step 4 — 等结构
- [ ] 价格不破 250/120 线（或回踩后站回）
- [ ] W底/双底成型，或双头/头肩顶已排除
- [ ] 突破/跌破已给满 3 天确认（非诱多/诱空）
- [ ] 小级别底背离出现（博反弹时），且处支撑位

## Step 5 — 等确认信号
- [ ] 缩量企稳后重新放量
- [ ] 出现大阳线 / 长下影转强 K 线
- [ ] 非高位巨量滞涨（非主力派发段）

## Step 6 — 三重共振 + 风控
- [ ] 大盘↑ + 板块↑ + 个股↑ 三者共振
- [ ] 仓位：不满仓，行情好最多 7–8 成、留 2 成风控
- [ ] 买点：回踩低吸，非追高
- [ ] 止损/止盈：到压力位减仓；破位先出
- [ ] 行为金融自检：非"主力拉高让你接"的派发段；非事件（IPO）兑现前一日

## 卖出纪律
- [ ] 反弹到前高压力位 / 波段末 → 减仓止盈
- [ ] 破 250 线或 3 天确认跌破支撑 → 先出
- [ ] 大盘共振消失 → 离场
