# 自选池批量复盘流程（150+ 只）

> 针对「复盘自选」类请求。核心矛盾：自选池上百只，但上下文与接口调用次数有限。
> 策略：**全池轻量扫描（分批 quote）→ 板块资金定方向 → 重点标的深挖（technical+fund_flow）**。

## 数据获取顺序（按此顺序，避免上下文爆炸）

### 1. 判大势（1 次调用）
- `data_quote` codes=`sh000001,sz399006,sh000300,sh000905,sh000852`
- 看 5 个指数的**20日/60日**涨跌：60日全线为负 = 反弹市非主升市 → 仓位上限 7 成。
- 补 `data_market_overview` type=`updown`：上涨家数占比、涨停数、**创250日新高数**（<50 家说明缺中期强势股，不宜追高）。

### 2. 板块轮动（1 次调用）
- `data_sector` mode=`ranking` kind=`industry` type=`mainNetInflow5d` order=`desc` limit=`15`
- 直接按「5日主力净流入」排序，同时输出今日涨跌与上涨家数比（upCount）。
- **判读**：正流入板块 = 资金真实去处；大幅流出板块若正好是自选中重仓方向 → 系统性风险，而非个股问题。

### 3. 全池扫描（分 3 批，每批约 55 只）
- `portfolio_watchlist` group=`1`（全部）拿代码清单 → 分批 `data_quote`。
- 每批 55 只时单次输出约 20KB，可控；超过约 60KB 系统会自动持久化到文件，届时用 Bash+python 解析文件而非读上下文。
- **扫什么**（只看 quote 就够筛的字段）：
  - `change_percent`（今日异动）、`volume_ratio`（量比>2 = 放量异动）
  - `chg_5d` / `chg_20d` / `chg_60d`（短期动能 + 中期趋势）
  - `high_52week` / `low_52week`（距极值距离，判断是否接飞刀）

### 4. 重点标的深挖（2 次调用，控制在 15 只以内）
- `data_technical` group=`macd,kdj,rsi,boll`（多码批量）
- `data_fund_flow`（多码批量，看 MainNetFlow5D/10D/20D）
- 只挑三类：① 持仓股 ② 核心跟踪股 ③ 当日异动（涨跌 >±3% 或量比 >2）

## 判读速查

| 信号组合 | 含义 | 动作 |
|---|---|---|
| MACD 0轴上金叉 + 主力5日流入 + 站上 BOLL 中轨 | 主升延续 | 持有 |
| MACD 0轴下金叉 + 主力5日流入 | 底部反弹待确认 | 观察，等放量 |
| 跌破 BOLL 下轨 + MACD 死叉绿柱放大 + 巨量 | 破位/主升结束 | 减仓离场 |
| RSI2 > 95 或 KDJ J > 100 | 短线极度超买 | 不追，等回踩中轨 |
| 今日大涨但主力净流入为负 | 散户抬轿、主力派发 | 警惕，不追 |
| 5日主力流入但10/20日流出 | 资金刚回流，趋势未翻转 | 观察 |
| 逼近 52 周低 + 主力持续流出 | 下降趋势 | 不接飞刀 |

## 输出格式

用户偏好：**结构化报告 + 表格看板 + 🔴🟡🟢 信号灯**。
按三段输出：① 持仓股处置 ② 核心跟踪 ③ 机会与风险。
每只给：现价 / 今日 / 主力5日 / 判定（一句话动作）。
结尾给**明日操作清单**（具体到价位的减仓线、低吸区、止损位）。

## 已知坑

- `portfolio_watchlist_add` / `batch_add` 返回 code 0 后，列表**可能延迟数分钟才刷新**（实测：药石科技 sz300725 添加后连续 6 次查询均查不到，约 30 分钟后才出现在列表首位）。
  处理：**不要重复添加，也不要轻易判定为失败**——重复添加无意义。稍后（隔数分钟或下次对话）回查确认即可；
  只有当多次回查（间隔 > 10 分钟）仍不出现时，才提示用户在 App 端手动添加。
- `data_market_overview` 的 updown 数据日期可能滞后一日（收盘后尚未刷新），需留意 `date` 字段。

## 全市场主升浪扫描（≈5000 只，排除科创板）

> 触发词：「复盘全市场」「全市场扫描」「5000只」。目标：在沪深全市场里筛出"多头排列+MACD金叉"的真主升浪，剔除用户无权限的科创板（sh688/sh689）。

### 关键约束（实测，重要）
- `tool_filter` 的 `expression` **只支持单条件**。`AND` / `intersect(...)` / 中缀 `intersect` / `&&` / 小写 `and` 全部报 `service error`（error_type=2）。
  → 必须拆成**多个单条件分别调用，再用 Python 取交集**。
- 字段名**带下划线**，且与输出 JSON key 一致：
  - 价格：`ClosePrice`（不是 CLOSE）
  - 均线：`MA_5` `MA_10` `MA_20` `MA_60` `MA_250`（不是 MA5/MA20）
  - MACD：`DIF` `DEA`（DIF>DEA = 金叉）
  - 估值：`PE_TTM` 等可直接用
- `universe: hs` = 沪深全市场（含主板/创业板/科创板/北交所？实测覆盖约 5010 只）。

### 步骤
1. **判大势 + 板块**（同上文 Step1/2）。
2. **5 个单条件全量拉取**（每个 limit 设大，如 6000，确保取全量；结果超 token 会自动落盘为文件）：
   - `ClosePrice>MA_5`
   - `MA_5>MA_10`
   - `MA_10>MA_20`
   - `MA_20>MA_60`
   - `DIF>DEA`
   命中规模参考：各约 2400~3700 只；五条件交集约 **854 只**（全市场），剔除科创板 sh688/sh689 后约 **822 只**。
3. **Python 取交集**：读 5 个结果文件 → 提取 `code` → `set.intersection` → 剔除 `c.startswith('sh688') or c.startswith('sh689')` → 合并各文件字段（ChangePCT/ClosePrice/MA_*/DIF/DEA）→ 按 `ChangePCT` 排序，存 CSV。
4. **资金验证**（核心区分"真主升浪 vs 涨停投机"）：对交集 Top60（按涨幅）分 4 批 `data_fund_flow`，看 `MainNetFlow5D` / `MainNetFlow20D`。
   - 5日&20日 均净流入 = 资金驱动主升浪（重点池）；
   - 涨停但 `MainNetFlow` 今日为负 / 5日净流出 = 主力派发，警惕。
5. **输出**：资金驱动重点池（按 5日主力净流入排序）+ 风险警示 + 明日操作清单（不追涨停、等回踩中轨）。

### 判读要点
- 全市场扫描结果里**涨停股占比高**（动量最强），但多为一日游投机；真主升浪 = 技术多头 + 主力持续流入，应**等回踩 5日线/布林中轨企稳再介入**，不在涨停板追。
- 交叉板块资金：重点池个股若落在 5日主力净流入板块（元件/软件开发/证券/工业金属/专用设备/航空装备等）则加分；落在半导体/通信/电池/医药流出板块则减分。

## 买入条件精筛（"符合买入条件的标的"）

> 在 822 只技术多头的基础上，进一步用资金维度做最终精筛，输出可直接低吸的标的清单。

### 关键约束（实测）
- `tool_ranking` 的 `metric` 须用 `tool_list_ranking_metrics` 列出的指标名（如 `cap_main_5d`=主力5日合计净流入、`cap_in_days`=主力连续净流入天数、`cap_main_net`=主力净流入），**不能用 `MAIN_INFLOW_5D` 这类别名**（报"未知排行指标"）。
- `tool_ranking` 不传 `universe` 时默认全市场；返回字段含 `MainSum5d`(5日)、`MainInDays`(连续流入天数) 等。
- `tool_filter` 单条件已落盘到 `.../tool-results/`；`tool_ranking` 结果在会话 jsonl 中，可用 Python 解析 `function_call_result` 里含 `"cap_main_5d"` 字符串的 `output.text` 提取 `data.stocks[].code`。

### 步骤
1. **资金排名取交集**：
   - `tool_ranking` metric=`cap_main_5d` limit=`300` order=`desc` → 全市场5日资金 Top300
   - `tool_ranking` metric=`cap_in_days` limit=`300` order=`desc` → 主力连续流入天数 Top300
   - 与 822 只技术多头取**交集** → 技术多头 ∩ 5日资金强（≈41 只，已剔除科创板）
2. **剔除过热/补跌**：`chg>=9%`(主板接近涨停) 或 `chg>=19.5%`(创业板涨停) 或 `chg<=-5%`(当日补跌破位) 的剔除——不追高。
3. **逐只资金核验**（核心，3~4 批 `data_fund_flow`）：对剩余约 41 只查 `MainNetFlow`(今日)/`MainNetFlow5D`/`MainNetFlow10D`/`MainNetFlow20D`。
4. **最终过滤（硬条件）**：
   - ✅ `MainNetFlow20D > 0`：**必须 20日净流入**，否则是"5日强但中期撤离"陷阱（实测剔除：比亚迪−20亿、牧原−4.9亿、平安−9.1亿、铜陵有色/云南铜业/驰宏锌锗/天洋新材/新大陆 等 20日均负）
   - ✅ `MainNetFlow`(今日) `> -1.6亿`：剔除当日巨幅派发（招金黄金−3.3亿、青山纸业−2.98亿、康盛股份−2.72亿）
   - ✅ 非科创板 / 非涨停过热 / 非当日补跌
5. **输出**：按板块分组 + 标注"★资金双强"(5日+20日合计>8亿)优先关注 + 单独列"已剔除陷阱股"及原因。

### 判读要点
- **20日主力净流入是分水岭**：很多"5日强"是短期脉冲或拉高出货（比亚迪/牧原/平安），必须看 20日确认中期资金方向。
- 最终符合买入条件的标的数量通常 **20~30 只**，多集中于当期资金主线板块（本次为有色/工业金属/贵金属/黄金）；板块共振（军工航空、券商资金流入）的更稳。
- 仍是反弹市（创业板60日负）→ **只低吸不追高**，等回踩 5日线/中轨企稳+放量，单只 −7% 止损。
- 复用脚本：`buy_filter.py`（ranking 与 822 交集）、`generate_buy_report.py`（fund_flow 核验+过滤+HTML 报告）。
