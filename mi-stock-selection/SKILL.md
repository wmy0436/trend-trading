# MI师/MI姐 选股方法论（蒸馏版）

## Overview

把 MI师/MI姐 多场直播（6/08–7/20）的操作建议与背后理论体系蒸馏成一个**自上而下、可执行的选股工作流**。
它不是给"买卖哪只票"的结论，而是给一套**判断框架 + 检查清单**，让使用者照着一步步筛出符合"底部+共振+回踩低吸"的标的，并规避高位接盘。

> 适用市场：A 股（含港股/红利视角）。所有结论均为主持人个人观点，使用时须自行判断，非投资依据。

## 方法论总纲（闭环）

任何选股都按此链路自上而下推进，缺一环不入场：

```
① 看大盘定方向（道氏/趋势：牛熊、级别、是否见底）
  → ② 看波浪定位置（当前第几浪 / ABC 哪一段）
    → ③ 选板块（轮动：高位三兄弟 vs 底部红利/医药/证券）
      → ④ 等结构（均线、W底/双底、压力支撑、底背离）
        → ⑤ 等信号（放量 + 大阳线 + 长下影 + 增量资金）
          → ⑥ 三重共振买点（大盘↑ + 板块↑ + 个股↑）
            → ⑦ 仓位风控（不满仓扛跌、回踩加、弹到压力位止盈）
```

一句话：**大盘未见底（日线 W 底 / 底背离）前不做；见底后只做"大盘+板块+个股"三重共振的回踩低吸。**

## 选股工作流（6 步）

### Step 1 — 判大势（大盘定方向）
- 用道氏框架判断当前是牛/熊、什么级别。散户只做确定性高的那段。
- 大盘未企稳 → 空仓观望；大盘与板块同向向上 → 才出手。
- 看月线级别风险："月线级别谨防走 21 年那种走势，七月底把三月底低点给破"（历史类比判大级别风险）。
- 给散户的级别门槛：至少 30 分钟级别底背离出现才值得动手，小级别小资金试错不值得参与。

### Step 2 — 定波浪位置（决定能不能买、买在哪一浪）
- 上涨分推动浪（1-2-3-4-5），回调走 ABC；三浪通常最强要过一浪高，C 浪是最后一跌。
- 证券案例："一浪上涨、二浪回踩走 ABC…B 浪反弹不高，反弹完还有 C 浪回踩，C 浪后才三浪上涨" → 等 C 浪回踩到位低吸，别在 B 浪追。
- 三浪规则："三浪上涨肯定要过一浪前高"。
- 高位科技："还要走五浪可能调三个月到半年" → 判调整时长，不急于抄底。

### Step 3 — 选板块（轮动：高低位切换）
- 高位"通信设备、元器件、半导体三兄弟"已见顶，只做下跌中反弹，不参与。
- 底部可低吸：医药、证券、保险、电信运营、石油/煤炭（红利）、银行/水务/化纤（红利护盘）、航天航空/商业航天（等事件反转）。
- 主线思维：资金集中在主线方向；已拉过一波的票慢慢进下跌趋势，不碰。
- 跟大盘不同向的板块：科技若跟大盘一起跳，就找趋势不同的板块避险。

### Step 4 — 等结构（均线 / 形态 / 背离）
- **均线生死线**：250 年线（不破低吸、跌破先出、刚突破是主升起点）；120 线支撑；趋势线/月线均线附近作中线买点；均线多头发散=主升，空头=不碰。
- **形态确认顶底**：W底/双底成型+放量=买；双头/头肩顶=逃顶；压力位=止盈目标。
- **突破/跌破给 3 天确认**：不追单根 K 线，三天内回不来支撑就是诱多。
- **底背离博反弹**：小级别（如 3 分钟/30 分钟）底背离+到支撑，轻仓博反弹，到前高压力即出，仅做反弹非长线。

### Step 5 — 等确认信号（量价 + K 线）
- **量价**：缩量企稳 + 增量资金进场 = 底部信号；高位巨量不涨 = 主力派发离场；跟主力资金流向选板块。
- **K 线**：底部出现放量大阳线 / 长下影 = 动手信号；只有缩量小阴 = 继续等。"没有一根大阳线拉上去你这也不是底"。
- **小阳建仓（潜伏期形态）**：低位连续小阳 + 温和放量 = 主力隐蔽吸筹，可轻仓跟随但**不构成买点**——真正的动手点在其后的放量大阳/突破。完整判据、量化口径与 TDX 全市场扫描公式见 `references/xiaoyang-accumulation.md`。

### Step 6 — 三重共振买点 + 仓位风控
- **三重共振**：大盘企稳 + 板块在主线 + 个股回踩到位，三者同向才出手，缺一不动。
- **仓位风控（贯穿每句建议）**：不满仓扛下跌（行情好最多七八层，留两层做风控）；回踩分批加；中线买点拿住不乱做 T；反弹到压力位/波段末减仓；先练"逃大跌"再谈赚。
- **行为金融警示**：识别主力"拉高让你接"的诱多派发；事件（如 IPO/SpaceX）兑现前减仓（预期兑现常杀跌）；利用散户情绪反向操作，绝不追涨。
